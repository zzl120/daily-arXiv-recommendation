In this paper, we studied how to optimize a semantic tokenizer for LLM-enhanced recommendation. Rather than treating semantic tokens as fixed upstream features, makes their assignment geometry responsive to downstream recommendation supervision. It applies a shared low-rank transformation around the frozen RQ codebooks and constrains deviation from the pretrained geometry. An interaction-conditioned gate further determines how much residual detail is exposed to the recommender. Experiments on four public datasets show that consistently improves AUC over conventional and LLM-enhanced baselines. Its benefits also persist across different recommendation backbones. The ablation results identify codebook adaptation as the main source of improvement, while prefix selection provides a complementary benefit. These findings support task-aware semantic tokenization as an effective interface between LLM-derived profiles and downstream recommendation models. Future work can extend this framework to temporal profile construction and other semantic modalities. All experiments are conducted offline on four public recommendation benchmarks without production deployment or direct interaction with users. The datasets do not contain names, contact information, or explicitly labeled sensitive attributes, though review text and behavioral histories may still reveal personal preferences. The LLM-generated summaries, embeddings, and semantic tokens derived from these data should not be regarded as anonymized, and the upstream language model may reproduce biases present in the source text. Because the benchmarks do not provide protected-group labels, we do not evaluate subgroup fairness in this work. As with engagement-oriented prediction methods in general, deployment should be mindful of popularity concentration and self-reinforcing feedback loops. Fine-grained user representations could also be repurposed for unintended profiling if access is not properly controlled. Responsible deployment would therefore benefit from subgroup fairness evaluation, profile validation, and appropriate data-governance and user-transparency mechanisms. Semantic tokenization provides a structured representation of this information by converting LLM-derived user profiles into discrete tokens. Modern recommender systems mainly rely on structured features, such as user IDs, item IDs, and interaction histories~. These features effectively capture collaborative patterns but contain little explicit semantic information. In practical applications, recommendation decisions often depend on semantic knowledge about item content and high-level user preferences that cannot be reliably recovered from interaction identifiers alone~. This need becomes particularly important in sparse and cold-start scenarios, where collaborative evidence is limited~. Large language models provide a practical way to introduce such knowledge by distilling item content and historical user behavior into natural-language profiles and dense semantic representations~. These representations complement conventional collaborative features with explicit descriptions of users and items, making LLM-derived semantics an increasingly important input modality for modern recommender systems. {image/fig1.pdf} As illustrated in Figure~, existing methods mainly incorporate LLM-derived semantics into conventional recommenders through three continuous-representation paradigms. The most direct approach treats semantic embeddings as auxiliary features and concatenates them with ID-based representations before feature interaction~. A second line of work aligns the semantic and collaborative representation spaces, typically via contrastive or matching objectives, making language-derived features more compatible with collaborative behaviors~. A third approach learns lightweight semantic adapters that transform or compress pretrained semantic embeddings before passing them to the downstream recommender, thereby retaining semantic knowledge without involving the LLM during online inference~. Despite their different designs, these approaches ultimately represent semantic information as dense, fixed-length continuous vectors. In large-scale applications, caching such vectors for millions of users and items and repeatedly fetching them for long behavior histories or large candidate sets can introduce substantial storage and memory-bandwidth overhead~. Moreover, a flat vector provides neither a compact, shared categorical interface across entities nor an explicit mechanism for accessing semantic information at different levels of resolution. These constraints motivate a storage-efficient semantic interface for downstream recommendation. Semantic tokenization provides a different interface for delivering semantic information to the downstream recommender, as shown in Figure~. It maps a dense semantic representation into a short sequence of discrete code indices, commonly using a residual-quantized variational autoencoder ~. Semantic tokens were first widely explored as autoregressive identifiers in generative recommendation~ and have subsequently been introduced as categorical input fields for conventional downstream recommenders via standard embedding lookups~. This interface is independent of how the tokenizer is trained: semantic tokens may be learned through reconstruction alone or further shaped by collaborative alignment and behavior supervision~. Recent systems also combine discrete tokens with continuous semantic features~, showing that these integration interfaces can be complementary. Despite these advantages, semantic tokenization is commonly implemented as a two-stage pipeline. A tokenizer is first trained through semantic reconstruction and then used to generate discrete IDs for a downstream recommender~. To incorporate recommendation-related information before this boundary, some methods additionally introduce collaborative or behavioral alignment during tokenizer construction~. Such alignment can make the resulting tokens more compatible with collaborative signals, but it remains an upstream proxy for the objective of the downstream recommender. Once the tokens are passed to the recommender, their assignments remain fixed with respect to its training objective. The recommender can learn how to embed and combine the assigned indices, but it cannot revise the quantization partition that produced them. As a result, if two semantic representations are mapped to the same token sequence, their tokenized inputs to the recommender are identical, even when distinguishing them would benefit the downstream objective. The central challenge is therefore to let the downstream recommendation objective revise token assignments while constraining the tokenizer's departure from the semantic structure learned during pretraining. To address the challenge, we propose , a framework that adapts a pretrained semantic tokenizer with downstream recommendation supervision. Optimizing semantic tokenization requires more than learning new embeddings for fixed token IDs. First, the assignment geometry should capture distinctions that matter to the recommendation while remaining anchored to the semantic structure acquired during pretraining. Second, the residual depth should expose an appropriate level of detail for each user--item interaction rather than applying the same fixed depth universally. These requirements give rise to two main challenges. First, hard nearest-code assignment prevents downstream gradients from reaching the tokenizer, while unconstrained codebook updates may distort the geometry acquired during pretraining. The tokenizer must therefore become task-responsive without drifting into a purely collaborative partition. Second, choosing the token prefix requires discrete continue-or-stop decisions, making it difficult to learn interaction-dependent depth without collapsing to a fixed policy. addresses these challenges while keeping the pretrained semantic encoder and base RQ codebooks frozen. At each residual layer, it applies a near-identity low-rank transformation shared by all codewords in that layer, allowing the effective assignment geometry to adapt while anchor regularization constrains its deviation from the pretrained codebook. A hard-forward, soft-backward straight-through estimator retains discrete token assignments during prediction while supplying surrogate gradients from the recommendation loss to the low-rank transformations and token embedding tables. further introduces an interaction-conditioned prefix-depth selector that determines how many residual layers to expose based on the current quantization state and interaction context. A straight-through continue-or-stop decision makes the selector trainable, while depth regularization discourages it from defaulting to the maximum depth. The resulting tokens retain the standard categorical-feature interface and can therefore be incorporated into different downstream recommenders without changing their basic architectures. Experiments on four public datasets show that OptST achieves the best performance across all datasets and produces positive gains with five additional recommendation backbones. Ablation studies further verify the effectiveness of codebook adaptation and interaction-conditioned depth selection. Our main contributions are summarized as follows: We study how pretrained hierarchical semantic tokenizers can be adapted for downstream recommendation. We frame this adaptation around two complementary dimensions: the codebook geometry should make token assignments responsive to recommendation signals, while the quantization depth should provide an appropriate semantic resolution for each user--item interaction. We propose , which keeps the pretrained semantic encoder and base codebooks frozen while adapting the effective RQ geometry through shared low-rank transformations, anchor regularization, and straight-through token assignment. An interaction-conditioned depth selector provides complementary control over the resolution exposed to the downstream recommender. We conduct extensive experiments on four public datasets using various recommendation architectures. The results demonstrate improved performance across the evaluated settings and clarify the respective contributions of codebook adaptation and prefix-depth selection. This difference is consistent with successive RQ layers serving distinct roles across datasets. Overall, downstream adaptation changes the token assignments without driving the codebook toward a degenerate solution. Large language models have increasingly been used to complement the collaborative signals learned from user--item interactions with open-world semantic knowledge~. Earlier content-aware recommenders extracted textual features from item descriptions and supplied them directly to prediction models~. Recent methods use LLMs to construct richer semantic representations at different granularities, including feature-level knowledge~, individual user behaviors~, generated user profiles~, and multimodal representations for sparse or cold-start entities~. Other studies adapt LLM-derived representations to specific recommendation data through prompting or lightweight semantic modeling~. These representations also differ in how they enter the downstream recommender. One approach treats semantic embeddings as auxiliary dense features and combines them with conventional ID representations~. Another aligns semantic and collaborative representation spaces before downstream prediction~. A third introduces lightweight adapters or field-level knowledge injection to transform semantic features into representations compatible with existing recommenders~. These mechanisms are not mutually exclusive, but they ultimately expose semantic information through continuous vectors. OptST focuses instead on the discrete semantic interface introduced by semantic tokenization. Semantic tokenization maps a dense representation to a short sequence of discrete codes using vector quantization or residual quantization~. In generative recommendation, these codes form the vocabulary through which items are generated. TIGER is an early representative that applies RQ-VAE to item-content embeddings and autoregressively predicts the resulting Semantic IDs~. Subsequent methods incorporate collaborative semantics, learnable tokenization, behavior-aware objectives, or contrastive quantization into the construction of Semantic-ID~ {lcrec,letter,eager,cost}. PLUM adapts pretrained language models to Semantic-ID generation at an industrial scale, while more recent work studies end-to-end Semantic-ID construction for generative recommendation and advertising~. ETEGRec couples item tokenization and generative recommendation through recommendation-oriented alignment, whereas DIGER allows the generative recommendation objective to influence Semantic-ID learning through differentiable assignments~. The same discrete interface has also been adopted by discriminative recommenders, where semantic codes enter as categorical fields and are converted into task-specific representations through embedding lookups. Better Generalization with Semantic IDs freezes a content-based RQ-VAE and learns representations of the resulting code sequences in an industrial ranking model~. UIST quantizes user and item semantics and introduces hierarchy-aware interactions between their token sequences~. UserIP applies vector quantization to LLM-inferred user profiles and couples profile learning with recommendation supervision~. Other methods introduce behavioral information before or during discretization: QARM aligns multimodal representations before quantization, DAS jointly trains residual quantization and collaborative alignment, and SaviorRec uses fixed RQ assignments to index a trainable behavior-alignment adapter~. RQ-GMM improves residual discretization through probabilistic distribution modeling, while TokenMinds generates discrete user-interest tokens together with dense user embeddings for production ranking systems~. These studies demonstrate that alignment and tokenization describe different design dimensions: alignment determines how behavioral supervision shapes a representation, whereas tokenization determines how that representation is exposed to the downstream recommender. Recent studies have also reconsidered how much of a hierarchical token sequence to use. UIST learns soft interactions among different hierarchy levels, whereas TokenMinds adopts a globally selected token prefix~. In generative recommendation, SA${}^{2}$CRQ, VarLenRec, and CapsID construct variable-length item identifiers using signals such as path entropy, item popularity, or routing confidence~. These methods adapt the identifier length at the item level for generative retrieval. OptST instead studies post-pretraining adaptation for a discriminative downstream recommender. It keeps the semantic encoder and base RQ codebooks frozen, uses the downstream recommendation objective to adapt the effective assignment geometry under low-rank and anchor constraints, and selects
