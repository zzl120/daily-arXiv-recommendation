Context-aware recommender systems typically acquire this information from location, time, or weather , or from textual reviews . While recommender systems use images extensively , they do so to enrich item or user representations , rather than to infer situational context. This is important since images are captured during the experience itself and can preserve contextual details such as the formality or ambience , that are not detailed in other contextual sources. Furthermore, context from textual reviews may lose these details since textual reviews are written after the fact and shaped by retrospective memory . In this work, we propose acquiring contextual information from images to improve recommender systems. Specifically, we define three types of image-based context categories: physical, social and modal context . These categories can be inferred from the image using visual cues, for example, the number of plates can be an indication of a social gathering. Our research questions are the following: : How does context acquired from images affect recommendation performance compared with established contextual signals? : Does image-based context improve recommendation performance when combined with other contextual and content signals? To answer these questions, we introduce ICE-Fuse, a pipeline for evaluating the value of different types of contextual features in RS. For each context category , we prompt a vision language model to return a contextual description for each picture, and then fuse those separate descriptions using a gating mechanism for a unified context representation. The context is then integrated into a well-known recommendation model. In this paper, we make the following contributions. First, we propose, for the first time, a new contextual signal from images to recommendation systems. Second, we introduce a designated evaluation pipeline, where we evaluate this signal compared to other signals, or as a complementary signal, in terms of recommendation performance in rating prediction tasks. Third, we identify several contextual features that are distinct to images, and are not present in other contextual sources. Our results show that image context does not outperform other context signals on its own in terms of rating prediction performance, but it could improve predictive performance when integrated with other context signals, showing that image context carries complementary contextual information to existing sources. Figure 1 illustrates the pipeline: context descriptions for each interaction are fused into a single image-context representation and incorporated into Review-aware Graph Contrastive Learning , a graph-based, review-aware recommendation model that we modified to integrate context during training, allowing image-derived information to refine the learned user and item representations. These representations are then used for rating prediction without requiring images at inference time. The chosen RS model is RGCL . RGCL was chosen to address an inference-time constraint: since images are unavailable at inference, the recommendation model must integrate contextual features into user and item representations during training. RGCL supports the integration of review information, and we modified it to incorporate contextual information. Context acquisition and fusion occur during training; the resulting representations $ are used directly for prediction. Rating prediction is performed by a lightweight fully connected network that operates only on these representations, first constructing a joint interaction representation and then mapping it to a scalar rating. To evaluate the usefulness of this signal, we present ICE-Fuse, a context evaluation pipeline that acquires physical, social, and modal context from review images and integrates it into a recommendation system. We find that image-based context does not outperform established contextual signals as a standalone predictor, but it consistently improves them when combined. A semantic analysis further shows that image- and text-derived context capture largely distinct concepts, supporting the view that image context is a complementary, rather than an overlapping, source of information. Although modest, these improvements are meaningful, as small gains in recommendation accuracy can drive substantial economic value . This study has several limitations. Context quality is assessed indirectly through downstream performance, in the absence of ground-truth labels. Available structured context is limited to city and coarse temporal features; finer-grained signals such as time of day are unavailable. In follow-up work we plan to evaluate image-based context across additional datasets, domains, and algorithms, and to study which visual cues matter most.
