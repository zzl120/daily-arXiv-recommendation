In particular, the shift from an adjacent source window to a target window can change user activity and item responses before enough outcomes are observed for retraining. This temporal drift can arise from daily changes in user activity, freshness- or event-driven item popularity, and delayed feedback that makes observed outcomes lag behind exposures~. We study this time-distribution-shift setting with an available source recommender, a fixed target exposure pool, and only a tiny fraction of target outcomes acquired before the next ranking update. The goal is to improve future user-grouped top-$k$ ranking while leaving the deployed backbone unchanged. Achieving this goal requires estimating a deployable correction from far fewer target outcomes than the degrees of freedom of a recommender. Conventional adaptation procedures are mismatched to this constraint because they use the scarce labels to estimate updates in high-dimensional, target-specific parameter spaces. Full target fine-tuning updates user, item, and interaction parameters from the small target label set, so its update is weakly identified and can overwrite useful source structure. Parameter constraints such as L2-SP reduce this drift, but still optimize in the full backbone parameterization~. Adapter- and LoRA-style parameter-efficient tuning reduce the number of updated parameters by learning inserted or low-rank transformations~; under our budget, however, they still estimate target-specific transformations across representation layers and leave the update directions weakly identified. MAML-style adaptation likewise relies on noisy task gradients in that high-dimensional space~. Cross-domain and cold-start methods transfer user representations or learn fast adaptation initializations~; their objectives are complementary, but they do not directly address a fixed temporal exposure pool in which the deployable change is a very small residual around a frozen ranker. The practical question is therefore not whether target feedback exists, but which correction directions it can support. A global residual is a robust answer because a few labels can estimate a small number of item-side directions. Yet a residual shared by every user cannot express that the same source-item direction may need different corrections for different source behavior regimes. Learning such user-specific corrections from target labels alone is precisely where scarce supervision is least reliable. The immediately preceding source window provides a distinct intermediate signal: unlike conventional domain adaptation, it uses labeled interactions from the same recommendation system and item schema to pretrain the correction space, while the target period only calibrates those source-supported directions. Following this principle, we develop as a modular framework for adaptation under temporal distribution shift. Its first module is a frozen-backbone residual adapter: a compact global correction uses source behavior statistics to define an update space while the deployed recommender remains unchanged. Its second module is staged source-to-target calibration: the residual is pretrained on the immediately preceding source window, then warm-started and calibrated with the sparse target outcomes, so the target labels estimate a small set of source-supported directions rather than a new recommender. Its third module is user-conditioned expert routing: a soft router maps stable source profiles and activity features to a mixture of residual experts, allowing the same global direction to receive differentiated corrections across user groups. These modules are optimized through the staged protocol and can be carried across successive target windows, providing a compact update path for continual serving.
