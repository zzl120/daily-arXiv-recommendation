Such shared contents would make records without the required evidence more likely to outrank the correct evidence when ranking relied only on query--memory similarity. Our key observation was that these similar records were not only competing candidates; they also provided a local neighborhood that could serve as a reference for each memory. In this paper, we proposed NEAR, a training-free framework that turned this potential source of confusion into useful matching information by constructing memory-specific local references. NEAR obtained query references from a precomputed table and combined residual representations with the original embeddings in a fixed index for a single approximate nearest-neighbor search. Experiments on eight long-context retrieval benchmarks showed improvements in mean Recall@10 and NDCG@10 across nine embedding models, with further gains in downstream question answering. In future work, we will extend NEAR to frequently updated memory banks and explore more compact reference representations. Complete comparisons with the other methods for each model appear in Appendix~. Memory retrieval aims to identify evidence from stored records to answer a query. Stored records with different factual details may share topics, entities, or events. Such shared contents would make records without the required evidence more likely to receive high similarity scores and outrank the correct evidence. In this paper, we use the information shared by these records to construct local references for query--memory matching. We propose ighborhood-ware esiduals , a training-free framework that uses these references to construct residual representations that complement the original embeddings. Specifically, each memory derives a reference direction from its neighbors, and each query obtains its reference from a precomputed table. Using these references, NEAR constructs projection residuals for both queries and memories. These residuals are combined with the original embeddings for a single approximate nearest-neighbor search over a fixed memory index. Experiments on eight long-context retrieval benchmarks show consistent improvements across nine embedding models. Downstream evaluations show that NEAR improves question-answering performance. A-Mem organizes structured memory notes into a dynamically linked network, while MemoryOS manages memories at different time scales through a hierarchical architecture . LightMem reduces memory-processing costs through information compression, topic-based consolidation, and offline updates . For retrieval, AssoMem uses an associative memory graph and combines relevance, importance, and temporal signals for ranking . EvoEmbedding instead learns context-dependent retrieval representations using a continuously updated latent memory . We focus on scoring queries against a given memory bank, without changing its content or updating the pretrained encoder. Contextual embedding methods incorporate surrounding text or other documents during encoding . Existing embeddings can be adapted for retrieval through supervised mappings or training-free corrections. Search-Adaptor learns transformations of pretrained embeddings from relevance supervision while keeping the encoder fixed . Training-free methods use neighborhoods or reference collections, but differ in whether they adjust scores or vectors. LC corrects similarity scores using local affinity estimates to reduce hubness . For cross-modal retrieval, NNN estimates matching biases from a reference database, while DBSN uses query and target reference banks to calibrate score distributions . Rather than correcting scores directly, InvGC transforms embedding vectors through inverse graph convolution with global or local reference sets . Residual-based methods compare or encode representations after removing a reference component. Local residual similarity constructs neighborhood-derived residuals for image re-ranking . PRQ-KMeans instead recursively removes selected-centroid projections to construct semantic IDs for generative retrieval and recommendation . For first-stage memory retrieval, memory-specific references can be computed offline, but a new query also needs a reference before any candidates have been retrieved. NEAR addresses this requirement by combining each memory's neighborhood reference with a precomputed query-reference mapping. It retains original similarity alongside residual matching and expresses their combined score as an inner product over a fixed memory index, enabling a single ANN search without preliminary candidate retrieval. Memory retrieval enables intelligent assistants to find evidence in past conversations and stored documents to answer current queries . A common approach is embedding-based retrieval, which encodes queries and memories separately and ranks memories by vector similarity . Memory embeddings can be computed and indexed in advance, allowing new queries to search the memory bank without re-encoding its records . This design separates offline memory processing from online query retrieval. In a memory bank, records with different factual details may share topics, entities, or events . When ranking relies only on query--memory similarity, such overlap would make records that do not provide the required evidence more likely to outrank correct evidence . However, these similar records are not only competing candidates. We argue that they also provide a local neighborhood that can serve as a reference for each memory. We turn this potential source of confusion into useful matching information by constructing memory-specific local references from the relationships among similar memories, as illustrated in Figure~. In this paper, we propose ighborhood-ware esiduals , a training-free framework that uses these local references for query--memory matching. Figure~ gives an overview of NEAR. For each memory, NEAR builds a reference from its nearest neighbors and removes the embedding component along this direction. A small precomputed table provides references for new queries without an initial search over the memory bank. The same projection yields a residual representation for each query. NEAR combines the original and residual representations so that the final matching score is a single inner product. Offline indexing enables retrieval through a single approximate nearest-neighbor search over the fixed memory index. We evaluate NEAR on eight long-context retrieval benchmarks using nine frozen embedding models. Across all nine models, NEAR improves mean Recall@10 and NDCG@10 over the original embeddings and the evaluated same-backbone baselines. Downstream evaluations further show that NEAR improves question-answering accuracy by 9.6 percentage points on LoCoMo with Qwen3-Embedding-4B as the retrieval model. Controlled comparisons show that local reference construction and memory--reference correspondence contribute to the retrieval gains. Additional analyses characterize parameter sensitivity and the trade-offs between retrieval quality, storage, and query latency, including the benefits of index compression.
