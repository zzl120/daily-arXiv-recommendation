However, optimizing distribution diversity or target-level interest separation ignores set-level retrieval geometry: sampled queries collapse onto overlapping ANN neighborhoods, while discrete top-$K$ lookup and single-target supervision block end-to-end coverage optimization. We introduce , a lightweight self-supervised post-training framework that coordinates queries from frozen flow-matching and diffusion retrievers toward complementary item coverage with negligible additional inference latency. CACO uses empirical retrieval frequencies across sampled reference queries as a relevance proxy, formulating a label-free coverage objective that improves recall across all 30 backbone--dataset settings in offline greedy selection experiments. To avoid the inference overhead of generating a large query pool, CACO employs a coordinated query adjustment network that combines inter-query bidirectional attention with gated relative directions, finally updating queries by bounded tangent-space projection and spherical retraction. During training, CACO applies tangential antithetic perturbations and measures each query's marginal gain via counterfactual single-query replacement, yielding an unbiased gradient estimator of smoothed set coverage across non-differentiable ANN search. Recent continuous generative retrievers---powered by diffusion~ and Riemannian flow matching on the unit hypersphere~---model user-conditioned query distributions in item embedding space and retrieve candidates via approximate nearest-neighbor search~. This generative process allows the system to sample multiple queries under the same user context and merge their retrieval results into a final candidate set. In fact, maximizing multi-query recall requires set-level complementarity: a query adds value only when it retrieves relevant items missed by the other queries~. Existing retrievers, however, typically promote distribution diversity or target-level interest separation without explicitly accounting for set-level retrieval geometry, leading to two structural failure modes. First, generative models such as DimeRec and X-Rec sample query trajectories independently under the same user context~. Even a diverse query distribution can yield highly overlapping ANN results, wasting limited retrieval slots on duplicates. Independent multi-sample rollouts exhibit similar target overlap and diminishing coverage gains in agent post-training~. Second, methods learn diverse interest representations under supervision from observed positive interactions~. Such target-item-level alignment overlooks actual set-level coverage: even when queries are matched to different positive samples, their top-$K$ retrieval neighborhoods in the embedding space can still heavily overlap. Figure~ illustrates both failure modes for a user interested in cat and dog videos under a budget of $L=3$ queries and $K=2$ videos per query. Query-unaware sampling repeatedly retrieves the same two cat videos, whereas interest-separated queries for cats, dogs, and playing still converge on the same two cat--dog interaction videos. Both cases consume six retrieval slots to return only two distinct videos. To expand coverage, a straightforward strategy is to increase the retrieval depth $K$ and deduplicate the results. However, such a compensatory strategy trades additional retrieval overhead for broader coverage, leaving the query generation process unchanged without explicitly optimizing each query's contribution to the merged candidate set. To achieve the complementary coverage in Panel~III, the central question we investigate is how to jointly optimize queries---balancing relevance and coverage---so that each retrieves relevant items missed by the others under a fixed retrieval budget. However, learning to coordinate queries toward this goal still presents two challenges. First, user interaction data provide only partial supervision: indiscriminately expanding coverage may introduce irrelevant items, while fitting a single observed target cannot capture the full range of interests that the query set should cover. We therefore need a coverage objective that approximates item relevance beyond the single observed target and rewards queries for covering complementary candidates. Second, even with a suitable coverage objective that can identify high-quality query sets, using it to train query generation remains challenging. On the one hand, coverage depends on the discrete candidate sets returned by approximate nearest-neighbor search, which prevents direct optimization of query generation through standard backpropagation~}. On the other hand, direct distillation of these high-quality query sets does not necessarily preserve their broader coverage of relevant items, because matching query representations and optimizing set-level retrieval coverage are different objectives. Preserving this coverage advantage during learning therefore requires training signals derived from actual retrieval results. To address these challenges, we propose , a lightweight self-supervised post-training framework that coordinates queries from frozen flow-matching and diffusion retrievers. CACO constructs a label-free, frequency-weighted coverage objective using item retrieval counts across reference queries sampled from the frozen base model as a relevance proxy. Each covered item contributes its weight only once, so retrieving duplicates yields zero additional gain. Applying offline greedy selection over a large reference pool confirms that this objective consistently guides query selection toward higher recall without ground-truth target labels. To avoid generating a large query pool at inference, CACO employs a coordinated query adjustment network that integrates context cross-attention, inter-query bidirectional attention, and gated relative directions, updating queries by bounded tangent-space projection and spherical retraction. During training, CACO applies tangential antithetic perturbations and holds the other queries fixed via counterfactual single-query replacement to measure each query's marginal coverage gain. This formulation yields an unbiased gradient estimator of Gaussian-smoothed set coverage across non-differentiable ANN search, improving complementary coverage while keeping the base generator, query count, and retrieval depth unchanged. We evaluate this goal using the next observed positive-interaction item as a sample of the user's latent interests. {2em} Generative retrieval in recommender systems follows discrete or continuous paradigms. Discrete methods generate semantic item IDs~} constructed through vector quantization~} or hierarchical clustering~}. Later work incorporates collaborative signals into tokenization and generation~} or aligns recommendations with user preferences~}. Alternative generation schemes include parallel decoding~}, latent-token-conditioned multi-tree decoding in LATTE~}, and masked diffusion in LLaDARec~}. Continuous methods generate query embeddings conditioned on user context for nearest-neighbor search. Diffusion-based methods model target representations via iterative denoising~} or incorporate multi-interest and quantized guidance for diversity~}. ADRec~} combines autoregressive modeling with item-level diffusion and multi-stage alignment, while PreferDiff~} formulates Bayesian personalized ranking using generation probabilities. For efficient generation, TA-Rec~} uses consistency regularization for single-step generation, FMRec~} adopts straight-path flow matching, and X-Rec~} combines anchor conditioning with Riemannian flow matching~} on the unit sphere. Order-agnostic continuous item identifiers also enable parallel generation~}. Building on continuous generative retrieval, CACO introduces a self-supervised post-training layer that coordinates queries from frozen flow-matching and diffusion backbones for complementary set-level coverage. Multi-interest retrieval represents each user with multiple vectors to capture diverse preference facets for parallel nearest-neighbor search. Early approaches extract interests from behavior sequences through dynamic capsule routing~} or self-attentive aggregation~}. SINE~} infers a sparse set of active concepts, while behavior clustering provides another way to construct multiple user representations~}. Subsequent work enriches interest modeling with temporal patterns and user profiles~}. Beyond interest extraction, disagreement and backward-flow regularization promote more informative and diverse representations~}, while graph-based item partitioning supports interest disentanglement~}. REMI~} further improves interest learning through interest-aware hard negative mining and routing regularization. At the supervision level, TiMiRec~} introduces target-interest distillation to guide multi-interest learning. Moving beyond single-positive supervision, MIMA~} groups concurrent positives within a request, models interest dependencies via a causally masked decoder, and applies Hungarian matching to exclusively assign distinct positive items to different interests. Similarly, continuous generative retrievers capture diverse preferences through conditional distribution modeling and query sampling~}. However, neither differentiated interest representations nor target-level positive assignments ensure broad coverage of relevant items: even queries matched to distinct targets may still retrieve heavily overlapping nearest-neighbor sets.
