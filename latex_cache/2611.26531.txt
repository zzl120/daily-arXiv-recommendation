We present an end-to-end agentic system that optimizes features across the fleet under resource constraints shared across models and those set per model, such as feature pipeline cost and serving throughput , respectively. In this system, LLM agents propose hypotheses, and deterministic tools execute experiments and verify them. For each model, an LLM generates and shortlists cross features from a combinatorial candidate space, and all features are then ranked by several importance methods. Feature blending mixes these rankings into a single selection, using Pareto fronts across tasks for multi-task models. An LLM Researcher agent then tunes the feature selection in 10--25 asynchronous trials under resource caps, and a trimming step keeps the pipeline cost within budget. As every feature performs differently across models and has its own serving and infrastructure cost, feature selection is an integral component of model performance and prediction relevancy. Due to these constraints, feature selection is a cost-sensitive trade between prediction accuracy and test-time feature cost~ that so far required manual reasoning and actions by ML practitioners. Recently, LLMs have been used to select~ and engineer features~, while LLM agents have shown increasing capabilities of running ML experimentation end to end~. These works study a single model in isolation. We design a scalable agentic system that generates, optimizes and selects features for every model without per-model engineering, under two kinds of budgets: per-model serving-cost caps and feature pipeline budgets shared across models. Two fleet-level mechanisms set it apart from per-model tools: a single retrieval LLM fine-tuned on feature outcomes from many models, so feature creation improves as more models are optimized; and fleet-aware pipeline-cost trimming, which optimizes each model's features against the rest of the fleet: a feature another model under the same budget already uses adds no pipeline cost. We make three contributions. LLM-driven Agentic Feature Creation that uses raw signals of features to reason and generate transformed feature candidates, with one generator fine-tuned on outcomes across the fleet . A novel feature-importance blending algorithm that combines rankings across tasks by Pareto optimality and across FI estimators, including ones scored on high-value traffic slices, by a tunable mixture . An agentic feature selection system that re-selects features at every refresh without manual additions or removals, balancing model quality against serving cost and the pipeline cost models share .
