Recommender systems are widely used in e-commerce and content platforms, where improvement requires repeated model design, training optimization, and experimental validation. Large language model agents increasingly automate this development cycle. Sustained autonomous improvement requires agents to improve both recommendation models and their development workflows. However, task-performance-driven approaches select updates mainly by candidates' final scores, without a separate optimization signal for experimentation quality. We therefore present , a dual-level framework that co-evolves recommendation mechanisms and agent orchestration toward recursive self-improvement. Inner evolution revises model and training code using task feedback to improve recommendation performance. Outer evolution scores the inner-loop experimental process, updates harness and skill rules using these scores and execution traces, and adjusts orchestration choices based on next-round scores to improve the quality of subsequent experiments. Experiments on MovieLens-1M and three Amazon Reviews 2023 subsets cover four recommendation methods and 16 settings. These code-editing and search methods let recommendation agents modify model logic beyond predefined alternatives. {Fig/intro.pdf} {Fig/dualevolve.pdf} Beyond model revision, agents can also improve the workflow used to propose changes, diagnose failures, and plan subsequent experiments. Recommendation metrics assess candidate quality, but do not fully capture the quality of experimental design and subsequent decisions. For example, after a controlled experiment yields no gain in the current setting, an agent may reduce retries in that direction and explore alternatives, or ignore failures and repeat similar changes. Both may leave the best model unchanged, but only the former uses evidence to redirect search. Model improvement alone cannot distinguish these behaviors. Alongside task-based model selection, agents therefore need feedback on experimental design, analysis, and subsequent decisions to improve their development workflow . Fortunately, automated agent-design research treats workflows and harnesses as optimization targets~. Meta-Harness proposes harness revisions from historical code, evaluation results, and execution traces~. In recommendation, recent studies extend search to architectures, diagnostic tools, and development workflows~. AgentX diagnoses traces to revise agent rules and checks edits through paired replay~. These methods provide a basis for improving workflows from accumulated experience. During an ongoing recommendation search, we further use feedback from experiments following a rule revision to guide subsequent orchestration choices.
