In this work, we investigated multi-layer PLM features for protein retrieval and showed that the best-performing layers vary across biological tasks, making conventional final-layer selection and naive all-layer averaging suboptimal. Building on these findings, we proposed QProtFuse, which adaptively fuses layer features according to the query and jointly optimizes protein and annotation retrieval through intra-modal and cross-modal contrastive learning. On Prot-Inst-OOD, QProtFuse achieves the strongest protein and annotation retrieval performance and improves downstream function description. Ablations confirm the value of query guidance and the complementary training objectives, while weight analysis reveals distinct fusion patterns for different biological queries. These findings highlight adaptive use of a single PLM's internal knowledge as an effective approach to retrieval-augmented protein function prediction. Our contributions are summarized as follows: We present the first systematic study of multi-layer PLM features for protein retrieval, showing that the best layer varies across tasks and using only final-layer features is suboptimal.
