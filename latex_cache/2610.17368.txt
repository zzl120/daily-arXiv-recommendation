We introduce an approach showing that explicitly incorporating hierarchical and attribute-level supervision into generative recommendation can simultaneously improve training efficiency and long-tail recommendation performance. Existing approaches typically optimize semantic ID prediction with a standard causal cross-entropy objective, which does not explicitly exploit the hierarchical structure of semantic IDs and can require substantial training to learn effective item representations. Moreover, data-sparse tail items often suffer from poor representations due to limited supervision, resulting in weaker long-tail recommendation performance. We address these challenges with HASTE , a unified training framework that introduces hierarchical and attribute-specific supervision. HASTE's Hierarchical Loss explicitly exploits the multi-level structure of semantic IDs, providing supervision at each level of the item hierarchy and substantially accelerating training convergence. Its Attribute-Specific Losses encourage the model to preserve fine-grained item attributes, leveraging the language model's inherent semantic knowledge to improve representations and recommendations for tail items. We extensively evaluate HASTE on a fashion recommendation benchmark and across multiple domains of the Amazon dataset. HASTE improves recommendation performance across datasets and item-frequency regimes. Sequential recommenders predict the next item from an ordered interaction history. GRU4Rec~ models sessions with recurrence, while SASRec~ and BERT4Rec~ use unidirectional and bidirectional self-attention respectively. All three represent an item as an atomic embedding in a table that grows with the catalogue, so a rare item's representation is learned almost entirely from its few occurrences, and retrieval needs a nearest-neighbour index maintained separately from the model. Generative retrieval removes the index: the model decodes the target's identifier token by token~. GENRE~ first cast retrieval this way, generating entity names autoregressively; DSI~ replaced names with structured semantic identifiers obtained by hierarchical clustering; and NCI~ added a prefix-aware decoder. P5~ first brought this seq2seq formulation to recommendation, and TIGER~ specialised it to semantic IDs, quantizing content embeddings with RQ-VAE~ and decoding the next item's codes from the history; because those codes are derived from content and shared prefix-wise, a rare item is no longer represented in isolation. HSTU~ showed the paradigm scales as a power law of training compute, and OneRec~ and OneRec-Think~ deploy it at industrial scale. In addition to the generation framework, item tokenization has also attracted considerable attention. Recforest~ applies hierarchical $k$-means to item text embeddings and uses the resulting cluster path as the identifier, while QARM~ replaces the learned quantizer with a training-free residual $k$-means. Furthermore, several studies incorporate collaborative signals into the tokenization process: MMGRec~ performs quantization over a user--item interaction graph, EAGER~ decodes behavioural and semantic tokens in two parallel streams, and LETTER~ augments a learnable tokenizer with collaborative and diversity regularisers. Chat-Rec~ prompts a general-purpose model with textual interaction histories, and GPT4Rec~ fine-tunes one to generate item titles; such models rank competently only over small candidate pools and remain sensitive to interaction order, item position, and popularity~. Generative recommendation~ formulates item retrieval as a sequence generation problem, where a language model generates the identifier of a recommended item conditioned on the user's interaction history. The effectiveness of this formulation therefore depends not only on the semantic structure encoded by the SIDs, but also on how effectively the training objective exploits this structure during generation. Semantic IDs can be obtained using residual quantization~, which represents an item embedding through a sequence of progressively refined discrete codes. Given an item representation $z$, residual quantization first selects a code from a coarse codebook and subsequently quantizes the residual using additional codebooks. The resulting representation can be expressed as z e_{s_{i,0}}^{ } + e_{s_{i,1}}^{ } + e_{s_{i,2}}^{ } + e_{s_{i,3}}^{ }, where $e_{s_{i,l}}^{ }$ denotes the code selected from the $l$-th quantization codebook. This construction induces a natural coarse-to-fine hierarchy among the semantic-ID codes: because $s_{i,l}$ is chosen to quantize the residual $z - _{k<l} e_{s_{i,k}}^{ }$ left after the first $l$ levels, level $l$'s code is defined only relative to the codes chosen at levels $0, ,l-1$. Consequently, earlier codes capture broader semantic characteristics of the item, while subsequent codes encode residual information that progressively refines the representation, and the semantic meaning of a later code is conditioned on the codes that precede it. A key implication, which we return to in Section~, is that an incorrect code at an early level changes the residual every later level is quantizing against — so errors at coarse levels are structurally more consequential than errors at fine levels. The objective provides supervision for each semantic-ID prediction while preserving the autoregressive generation process. Given a user interaction context, the model autoregressively generates an item's semantic ID as a sequence of discrete codes obtained through residual quantization. By exploiting the multi-level structure of semantic IDs and incorporating confidence-aware gating, level weighting, and scheduled sampling, HASTE improves hierarchical prediction. Attribute-specific auxiliary objectives further preserve fine-grained item information, particularly for tail items. Experiments across multiple Amazon domains and a large-scale fashion dataset show consistent improvements over strong baselines, with ablations confirming the complementary benefits of the proposed components. Some limitations of our work include its dependence on the quality of the underlying semantic-ID hierarchy and the availability of reliable attribute information for attribute-specific supervision. Moreover, our evaluation primarily relies on offline metrics, which may not fully capture real-world user satisfaction and long-term engagement. Future work will explore adaptive hierarchy construction, richer multimodal and behavioral attribute supervision, and online evaluation incorporating user feedback and long-term engagement. HASTE is designed to improve generative recommendation and does not directly use sensitive user attributes. However, recommendation systems can amplify existing popularity biases and may disproportionately favor frequently interacted-with items, potentially reducing exposure to less popular or tail items. HASTE explicitly incorporates attribute-aware supervision to improve tail-item representation, but this does not guarantee fairness across all products or user groups. In addition, the use of catalog and behavioral data may introduce privacy concerns depending on the data collection and deployment setting. In practice, appropriate data anonymization, access controls, and privacy-preserving data practices should be applied. Finally, the framework should be evaluated for unintended recommendation biases before deployment, particularly in settings where recommendations can influence user choices or commercial outcomes.
