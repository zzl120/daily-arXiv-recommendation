 LLM-based personal agents are emerging as persistent carriers of user semantics and intermediaries between users and recommendation platforms, maintaining richer user knowledge locally. As agents interact with one another, the conventional relation evolves into a information pathway, enabling distributed user-side information to complement item-side information. This new pathway, however, defies conventional recommendation: evidence is scattered across mutually opaque agents and reachable only through bounded queries, only a small portion of it is relevant to the current recommendation decision, and the responses returned by different agents are semantically heterogeneous. We therefore recast recommendation over the as a problem under a finite evidence budget by deciding what to ask and what to keep, rather than learning from aggregated data. We propose , a user-agent-oriented framework that progressively acquires and fuses distributed evidence for each user-item decision while keeping underlying agent memories local. It grounds each decision in platform-provided item semantics and task-relevant evidence from the target user agent's private memory, and conditionally queries neighboring user agents for complementary preference patterns when local evidence is insufficient. Classical recommendation methods predominantly operate on direct user–platform interactions, from which they learn user and item representations to model user preferences~. Although this platform-centric setting has enabled substantial progress in recommendation, interaction signals remain ambiguous. Because observed behaviors reveal only the users' actions but not the underlying intentions, aggregating such heterogeneous signals into user representations could emphasize recurring patterns while obscuring transient or evolving preferences. Consequently, similar behavioral histories would correspond to different individual preferences, while the same user exhibits distinct needs under different contexts~. With the development of LLMs in recent years, LLM-based personal agents are beginning to change this interaction model. Consumer-oriented agent products, such as Alibaba's Qwen and Amazon's Alexa+, combine historical user information and current context to infer intentions and preferences~. On this basis, an agent act on the user's behalf to interact with the platform by formulating searching for specific items, examining ranked results and comparing candidates. In contrast to conventional user-platform interactions, where user actions are observed as isolated stateless events, an agent maintains the evolving states across requests. Meanwhile, memory-oriented agent systems show that an LLM agent can organize and retrieve long-term user-specific information . A user agent plays two roles in this new interaction model. As a persistent carrier of user semantics, it accumulates the user's preferences, feedback, and context across sessions and services, maintaining a local user profile richer than what any single platform observes. As an intermediary, it stands between the user and platforms, interpreting the user's intentions and acquiring information on the user's behalf. However, richer local knowledge does not guarantee sufficient task-time evidence: when prior experience offers little analogous signal for the candidate item, an isolated agent lacks the reusable preference patterns needed to ground its decision, and must look beyond its own memory. Emerging agent-native communities provide a basis for connecting distributed information. Within this setting, when private memory lacks available information for a recommendation task, a user agent can discover and collaborate with agents that provide relevant information . In a macro view, task-oriented collaborations between user agents constitute the edges of the Agent Web . Crucially, such collaboration only exposes task-level capabilities and responses with the internal states unseen: protocols such as A2A make agents discoverable while leaving their internal memories and reasoning states opaque . Agent-native communities are not limited to interactions among user agents: recommendation platforms also participate in the through functional agents that expose item-side information~. Existing recommendation research does not directly address this configuration. LLM-based recommendation methods use LLMs to improve the representation of user intentions, item semantics, interaction sequences, and recommendation instructions . Agent-based approaches further introduce planning, tool use, user simulation, reflection, feedback loops, and multi-agent coordination into recommendation . These studies demonstrate the potential of agent reasoning and memory, but generally organize agents within a platform-controlled workflow or allow the platform to construct and update reusable agent states. Meanwhile, research on the Internet of Agents and the Agentic Web studies general-purpose agent discovery, communication, and collaboration , but does not specify how independently maintained user-side information should be combined with platform-side information for a specific recommendation decision. This gap changes the central problem from aggregating more user information to eliciting the information required by the current decision. We therefore ask: This question presents three challenges. First, the relevant information is distributed across participants whose internal states are mutually inaccessible. Platform knowledge, agent local information, and external agent feedback describe different aspects of the task and may differ substantially in semantic perspective. A recommendation task, specified by a triple $t= $ with target user $u U$, candidate item $i I$, and decision time $ $, is to predict the preference $Y_t$ of user $u$ toward item $i$ at time $ $. Solving task $t$ in the faces two constraints. First, task-relevant information is distributed across agents whose memories remain mutually isolated, so centralized training over aggregated data is infeasible. Second, agent memories accumulate interactions from diverse contexts; indiscriminately incorporating unrelated records or weakly aligned agent responses dilutes the preference signals relevant to the current task~. Effective recommendation therefore requires concentrating dispersed information into compact evidence that preserves task-relevant semantics while excluding distracting content. We accordingly formulate recommendation over the as a task-time information acquisition and evidence fusion problem. For task $t$, let $ R_t$ denote the information acquired from distributed agent memories through query--response interactions, and let $Fuse $ denote the function that identifies task-relevant content within $ R_t$ and aligns heterogeneous sources into the evidence for prediction. The problem is to determine which information to acquire as $ R_t$ and how to fuse it, such that the resulting prediction $ Y_t=Fuse $ approximates the true preference $Y_t$. Traditional recommenders follow a platform-centric pipeline that learns reusable user and item representations from centrally collected interactions. Matrix factorization, pairwise ranking, and neural collaborative filtering model global preference patterns~, while sequential methods capture temporal dynamics and contextual dependencies~. Their effectiveness relies on aggregating behavioral histories and optimizing a platform-wide ranking objective. Even when recent interests or high-order relations are modeled, the underlying evidence is still aggregated and interpreted centrally. Evidence processing and preference estimation therefore remain controlled by the platform, which differs from the Agent Web settings. LLM-based recommendation introduces language representations and semantic reasoning into recommendation. Existing methods formulate recommendation as instruction following, textual sequence modeling, or semantic item generation~, and incorporate collaborative semantics or augment sparse interaction graphs~. Surveys further summarize the potential of LLMs for generative and general-purpose recommendation~. Retrieval-augmented and graph-grounded approaches improve grounding by injecting documents, collaborative signals, or graph contexts into LLM reasoning~. In most cases, however, retrieval remains a platform-side operation rather than an evidence-acquisition decision made by a user-owned agent. LLM-powered agents extend this paradigm with planning, tool use, memory, reflection, and environmental interaction~. Recommendation agents can invoke tools, plan zero-shot procedures, coordinate specialized modules, and support interactive recommendation~; other approaches simulate users or refine recommendations through agentic feedback loops~. Memory-oriented studies further address long histories, reusable personas, lifelong preference modeling, and collaborative memory~.
