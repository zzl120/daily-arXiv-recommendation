Both lists show the observed item at the same illustrative position.} Recommendation on Web platforms requires finding items that satisfy a user's needs, even when those needs do not specify a concrete retrieval request. Interaction histories and other available user context provide evidence of preferences, inducing several plausible directions for the next recommendation. Existing approaches express these preferences through discriminative item scores~ or distributions on discrete item identifiers~. Query-based recommendation makes this intermediate preference expression explicit in natural language, then uses a retriever to find matching items across the catalog~. A single user can have multiple interests~. For example, a reading history containing , , and may suggest interests in cognitive science, behavioral change, or human achievement. Large language models can draw on semantic knowledge to turn these plausible interests into separate retrieval requests, with prior work demonstrating the value of multiple queries for recommendation~. This provides an open-ended language representation of preferences without requiring the generator to select an item code or enumerate a candidate list. Title-supervised and prompting-based recommenders provide two ways to obtain retrieval text. GPT4Rec trains its generator to predict target item titles before using the generated text for retrieval~; BIGRec also uses target item text for supervised adaptation~. QueRec~ generates personalized queries through prompting without LLM fine-tuning. We study a complementary learning formulation: next-item interactions supply query supervision and evaluate the recommendation outcomes of generated queries . An observed interaction identifies an item to recover, but does not prescribe a unique query to reproduce. Several expressions may retrieve the same item, while the interaction log does not annotate which expression to imitate. We address this supervision problem through : generated expressions that retrieve the observed item successfully become training targets. The item label thereby specifies an admissibility criterion for queries without fixing their wording. Admissible individual expressions and useful query combinations pose different ranking problems. Even the complete vector of target ranks across queries does not determine the fused recommendation outcome: the positions of competing items across the lists also matter. Our analysis formalizes this distinction, motivating of generated sets using the observed item's rank after reciprocal rank fusion. Log-rank feedback then supplies relative comparisons among sets for the same context~. Its cutoff-risk decomposition explains how it emphasizes improvements near the head while retaining feedback beyond a fixed recommendation cutoff. These choices define }, a compact framework linking item-level supervision to recommendation-level evaluation. Item-verified supervision constructs the expressions to imitate; fusion-aware refinement evaluates newly generated combinations; the supervised reference constrains policy change through a KL penalty. The same frozen retrieval interface supplies both supervision and outcome evaluation, while only the query generator is updated. This makes recommendation queries a learned interface between user context and item retrieval. At inference, the generator expresses user preferences as several queries, the retriever executes them, and reciprocal rank fusion combines the resulting item lists~. The item index and retrieval model remain fixed, and the learning procedure requires neither annotated queries nor a separate learned reward model. We evaluate on three public recommendation datasets and observe state-of-the-art overall recommendation performance among the evaluated methods. Controlled MovieTV comparisons trace title supervision and retrieval-verified supervision through SFT and subsequent policy refinement. These comparisons connect the design choices to their effect on recommendation quality; further experiments examine multiple queries, model choices, and domain transfer. The design separates three questions: what an observed item can supervise, how query combinations affect item competition, and which recommendation depths the loss emphasizes. An item label specifies a retrieval target without prescribing a unique expression. Item-verified supervision uses it to define admissible queries; Appendix~ formalizes this selection by conditioning on acceptance. Admissibility alone does not characterize the outcome of combining queries. Lemma~ gives two sets of retrieval lists with identical target-rank vectors but different fused target ranks. The difference arises from competing items across the lists: even the full vector of individual target ranks, and therefore its best or mean, cannot determine the fused outcome in general. Query-based recommendation connects language generation with item retrieval, with the closest approaches differing in how they train or construct the generated text. GPT4Rec fine-tunes a language model to predict target item titles, then uses the generated text with BM25 to retrieve recommendations~. Its generator learns target-title likelihood; retrieval ranks do not supervise its parameter updates. BIGRec similarly uses target item text for supervised adaptation before grounding generated text to actual items~. Rather than adapting the generator to target text, QueRec~ generates enriched item descriptions and personalized queries through prompting without LLM fine tuning, and integrates semantic retrieval with collaborative signals. This approach uses an LLM to express preferences, but does not learn its query generation policy from the retrieval outcomes. Rec-R1 couples LLM-generated text with fixed recommendation models~. Concurrent QueryAgent-R1 combines memory-based user profiling with a search agent for proactive e-commerce query recommendation~. The focus of is how item-level observations supervise an intermediate query interface. Retrieval verification converts those observations into query targets without prescribing their wording, while policy refinement evaluates generated sets at the fused ranking used for recommendation. This connects supervision construction and recommendation-level outcome optimization through a fixed retrieval system. Discriminative recommenders score items through learned representations, with sequential models deriving user representations from interaction histories. Natural-language interfaces broaden how users interact with recommenders~. Agentic approaches further introduce memory, tool use, and interaction between agents~. The candidate-ranking protocols considered here provide a small item set to the LLM, allowing direct reasoning about candidate content. instead generates retrieval queries without candidate enumeration in its prompt, and ranks the supplied candidates by retrieval when evaluated in this setting. We presented , a framework for learning recommendation queries from item interactions through a fixed retrieval system. Its design separates two learning decisions: retrieval verification identifies useful expressions to imitate, and policy refinement evaluates newly generated query sets through their combined item ranking. The same retrieval interface supports both stages, while only the query generator is updated. Controlled comparisons show the benefit of retrieval-verified supervision over title imitation and the further gain from policy refinement. The resulting query interface supports recommendation over the full item set without requiring query annotations or a learned reward model. Future work can adapt the query budget to user context and examine alternative fusion functions within query learning. Another direction is to study query refresh policies for changing user interests and item collections. The separation between query generation and retrieval also supports exploring additional retrieval backends. Broader questions of verifier reliability when LLMs arbitrate between prior knowledge and retrieved evidence are also relevant to retrieval-augmented systems more generally~.
