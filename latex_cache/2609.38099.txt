The core idea behind PromptReps~ is that LLMs can be directly prompted to generate effective representations for retrieval. For PromptReps, this is achieved by extracting the final hidden-state representation that the LLM produces when it is prompted to generate a representative word which summarizes a given input text. More formally, PromptReps goes as follows: Given some input text $x$ -- either a query $q$ or a document $d$ -- and a prompt template -- which we denote as $P $ -- that asks the LLM for a ``single word that represents $x$ for a retrieval task'', PromptReps runs a single forward pass over $P $ and extracts the LLM's final hidden state immediately before the language modeling head as the representation for retrieval: \[ _q &= _{} ). \\ _d &= _{} ). \] To enable retrieval, $_d$ is pre-computed for each document in the corpus, $=\{d_1, d_2, , d_n\}$, and stored in an ANN index. At query time, $_q$ is computed ``on-the-fly'' and searched against the index. We hypothesize that PromptReps-Dense has two potential limitations. The first is that, without task-specific relevance examples, the LLM lacks sufficient knowledge of what relevance ``looks like'' for a given search task, making it difficult to generate representative words that are well aligned with the retrieval objective. The second limitation is that PromptReps relies on an instruction alone, without any shared context to connect the query and document encoding tasks; each encoding task is performed independently without knowledge of how the other represents text, which may limit how well their inner products can capture relevance. Large language models have emerged as powerful backbones for modern dense retrieval systems thanks to their rich world knowledge and text understanding capabilities~. But ``out-of-the-box'', their hidden states do not automatically yield effective embedding representations for dense retrieval. As a result, strong LLM-based dense retrieval systems typically rely on additional retriever training, often through supervised~ or unsupervised~ objectives. Building strong LLM-based embeddings that require remains an open challenge. In this paper, we seek to address this challenge by drawing on two insights from the broader literature on zero- and few-shot dense retrieval. The first is that, given only a few human-labeled in-context examples, LLMs can be prompted to produce effective synthetic data for training downstream dense retrievers~. But as we aim to build LLM dense retrievers that do not require training, we draw on a second insight from PromptReps~, which demonstrated that LLMs can be directly prompted to generate query and document representations for retrieval. However, one limitation of PromptReps is that query and document representations are derived independently via separate prompts, without any shared context connecting the two encoding tasks. Inspired by these insights, we ask: To answer this, we introduce , an approach for prompting LLMs to produce high-quality dense representations without requiring any form of retrieval-specific training. To do so, combines the ease and simplicity of directly prompting LLMs for representations with the ability of LLMs to infer task-specific retrieval cues from only a few in-context examples. Like PromptReps, derives embeddings by prompting an LLM to generate a representative word for a query or document and extracting its final hidden state. Unlike PromptReps, which relies on an instruction alone, primes this word generation process using query–document pairs that illustrate how the LLM represents the given document through PromptReps-generated words. These demonstrations provide a shared context for query and document encoding with the aim of producing representations whose inner products better reflect relevance. In summary, our contributions are twofold. First, we propose , a simple approach for extracting -- via prompts -- dense retrieval representations from LLMs using in-context examples. Second, we comprehensively evaluate on various retrieval datasets from BEIR~, and show that with only a in-context examples, LLMs can produce strong representations for dense retrieval without requiring retrieval-specific training. In particular, we demonstrate that improves the effectiveness of prompt-based LLM representations. When compared against LLM2Vec-Gen~, a highly effective self-supervised dense retriever, is competitive.
