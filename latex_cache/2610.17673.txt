As user profiles accumulate over time, they inevitably become noisy, making effective user profile denoising a fundamental challenge. Existing personalized conversational query reformulation methods rely on the black-box reasoning capability of LLMs to expand the original query with relevant user profile phrases, producing a verbose query for retrieval. Such rewrite-then-retrieve pipelines reduce user profile denoising to the explicit selection of profile phrases in the sparse token space, separating personalization from downstream relevance modeling. Consequently, they often fail to identify user information that is truly beneficial for retrieval. To enable retrieval-aware user profile denoising, we propose Personalized Conversational Dense Retrieval , which learns to jointly project the conversation history and user profile into a latent embedding space dedicated to retrieval. By inheriting the context denoising capability from conversational dense retrievers, PCDR requires only a handful of personalized relevance annotations for training. Personalized Conversational Search systems additionally condition conversational retrieval on a profile of persistent facts about the user. The TREC Interactive Knowledge Assistance Track ~ targets this problem by providing human-curated information-seeking conversations accompanied by user profiles consisting of natural-language statements. Figure~ shows an example: the current question depends on the dialogue history and on only a few statements of the user profile, and PCDR encodes the conversation and the full profile into a single personalized query embedding. {Figures/pcdr_example.pdf} This year, iKAT 2026 introduced an interactive task that requires the participating retrieval system to interact with the same simulated user~ across multiple conversation sessions. Submitted systems should continuously extract new persistent user facts and append them to the profile throughout these sequential interactions. The profile therefore grows monotonically as the dialogue unfolds. This accumulation comes at a cost. Long-term memory mechanisms for conversational agents are typically designed to add new information more readily than they consolidate or remove it~. Over extended interactions, the profile becomes long and accumulates statements that are only loosely related to any individual question. The resulting profile is informative but noisy: information that is decisive for one question may distract retrieval for the next, and the relevant profile statements cannot be determined in advance. This problem is amplified by the prevailing approach for exploiting user profiles: Personalized Conversational Query Reformulation ~. Given the full conversation history and the user profile, PCQR employs Large Language Models to generate a personalized and de-contextualized self-contained query to submit to off-the-shelf ad-hoc retrievers. However, previous studies~ showed that this process can cause query drift, where LLMs incorporate weakly related profile phrases into the rewritten query. As profiles grow through continued interaction, this problem becomes increasingly severe. We argue that this limitation arises from the intermediate rewritten query. First, personalization must be verbalized through explicit profile phrase injection in the discrete token space, which cannot fully express implicit, retrieval-relevant meanings. For example, a user's interest in may imply when searching for books or when searching for clothing. Second, queries generated by zero-shot LLMs are not directly optimized for retrieval. Even when the selected profile phrases are relevant, inserting them into the query does not necessarily produce a good search query. To overcome these limitations, we propose , which performs retrieval-aware user profile denoising directly in the dense retriever's latent embedding space. PCDR jointly encodes the conversation history and user profile into a single query embedding, allowing implicit personal information to influence retrieval without being explicitly verbalized in a rewritten query. Trained with a small number of personalized relevance judgments from the iKAT 2023--2025 datasets, PCDR learns to condition the encoding of the contextual dense embedding only on the relevant parts of the user profile that are also useful for search. This can be viewed as an implicit user profile denoising process that is optimized directly for the retrieval task. We further distill knowledge from personalized human rewrites to stabilize training. Figure~ illustrates the two-stage continual training that produces PCDR from a base Qwen3 0.6B embedding model. Visualization analysis illustrates that PCDR focuses on fewer but more essential profile signals than explicit profile phrase selection. {Figures/continual_PCDR.jpg} We evaluate PCDR by incorporating it in a search system participating in the online interactive track of iKAT 2026. The results show that for complex real-world information needs, PCDR alone produces effective personalized retrieval results, while combining it with heterogeneous retrievers provides further improvements. Conversational search aims at resolving context-dependent utterances against a long and noisy dialogue history~. Instead of rewriting the utterance into a self-contained query~, conversational dense retrieval encodes the whole session into a single query embedding, learning to denoise the conversation in latent space and to keep only the context that reveals the current search intent~. CDR has since been refined in many directions~ and extended to LLM-based embedders~. PCDR is continually fine-tuned from a CDR checkpoint, so that it inherits the ability to denoise a long conversational context and can apply it to the user profile, preventing the profile from overloading the search intent with irrelevant information. A similar idea is widely used in personalized dense retrieval, where various forms of user information are jointly encoded with the query: latent or ID-based user embeddings~, categorical profile features~, behavioral histories such as past queries, clicks, and purchases~, and structured textual constraints~. The retrieval targets range from products and videos to agent skills. Instruction-following retrievers have also been studied with long-form personalized instructions~. In these tasks, although complicated, the information need is still clearly stated by the instructions, not demanding as much reasoning effort as inferring the search intent implied by a stand-alone user profile. None of these works conditions large-scale web passage retrieval on a persistent, unstructured natural-language profile of a specific user together with that user's conversational history. Such natural human--agent interactions are noisier, and their personal intents are often only implied by the interactions of phrasing nuances in both profiles and dialogues, which makes dense retrieval considerably harder. Personalized conversational information retrieval studies exactly this setting~. Existing systems mostly follow the Personalized Conversational Query Reformulation paradigm: they rely on the implicit incorporation of profile statements based on the parametric knowledge of LLMs to produce a plausibly personalized search query, then pass it to off-the-shelf retrievers and rerankers~. Since such LLM-based user profile denoising that is not trained in favor of retrieval can be imperfect~, PCDR instead trains a retrieval model to denoise the user profile directly. Following existing practice in CDR~, only the query side of the PCDR dual encoder is fine-tuned, while the document encoder is kept frozen. More specifically, a query encoder $f_ $ encodes the current utterance together with the dialogue history and the user profile into a single vector $q=f_ $, and passages are ranked by the cosine similarity $ $ between $q$ and their frozen embeddings; only $ $ is trained. Unlike the reformulate-then-retrieve pipelines of our previous systems~, PCDR forms no intermediate rewritten query and consumes the conversation and the user profile directly. PCDR is trained and validated entirely on iKAT data and tested online on the iKAT 2026 simulated users, as reported in Section~; no 2026 relevance labels are used in training. We use the graded relevance judgments of the TREC Interactive Knowledge Assistance Track ~ 2023--2025, a personalized conversational benchmark over the ClueWeb22-B web corpus~. Each conversation is paired with a user profile as defined in Section~. Each turn provides the context-dependent utterance $u_t$, a human that resolves it into a self-contained query and is used only as a distillation teacher in Section~, and, for the relevant turns, human annotations of which profile statements are relevant. The denoising happens in embedding space, which is exactly where dense retrieval is robust to verbosity and where reformulation is not. In this paper, we tackle the problem of over-personalization caused by the excessive integration of user profile terms in existing personalized conversational query reformulation. We propose to perform user profile denoising in a latent semantic space, optimized directly for retrieval performance. In this way, more precise user information is integrated into the latent representation of the conversational information need to enhance search. Specifically, we train PCDR, which performs retrieval-aware user profile denoising directly in the dense retriever's embedding space. Initialized from a conversational dense retriever, PCDR requires only a small set of previous-year iKAT relevance judgments, augmented by light distillation from personalized human-rewrite embeddings. Online evaluation on the iKAT 2026 interactive runs shows that PCDR alone can produce satisfying tailored search results, and combining it with heterogeneous retrievers yields further improvements. Our visualization analysis further illustrates that the profile denoising goes beyond shallow semantic relevance. Future work includes removing the reliance on distillation from human query rewrites, so that PCDR is trained from relevance signals alone and no longer needs rewritten queries at any stage. It also includes scaling training with synthesized end-to-end personalized conversational retrieval datasets and studying continual adaptation from ad-hoc search to conversational search and ultimately personalized conversational search.
