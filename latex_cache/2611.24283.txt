We present X-split ARGUS, a framework for ad ranking whose history compressor and online ranker are trained end to end. The compressor encodes past interactions into a compact set of tokens that are computed offline and reused across candidates, while the online ranker scores ads through cross-at\-ten\-tion to these tokens and representations of recent events. Training combines an autoregressive loss for click feedback with distillation of candidate-specific click logits from a larger teacher that scores each candidate using the uncompressed history. The number of compressed history tokens and the length of recent history can be adjusted to fit serving compute and latency budgets. Offline evaluation shows a 0.81\ production baseline. Deployment in a large-scale real-time bidding system increases online inference cost by 15\ An online A/B test against this baseline yields relative gains of recommendation systems, CTR prediction, sequential modeling, user interest modeling, knowledge distillation, ranking models Accurate click-through rate prediction requires user representations that capture persistent preferences, respond to recent intent, and retain behavioral signals relevant to each candidate ad. Longer histories can provide additional evidence for these predictions, and recent sequential models demonstrate the benefits of scaling behavioral context and model capacity~. However, encoding extensive histories for each ranking request increases GPU computation and memory traffic, while processing that depends on the candidate can limit reuse across ads. At production request rates, these costs must fit strict compute and response latency budgets, making the representation of historical context a central deployment decision. Existing systems already address important parts of this problem. TransAct~ and LLaTTE~ combine precomputed user representations with online processing of recent behavior, while VISTA~ learns reusable history summaries for candidate-aware scoring. TM20K~ further combines sequence compression with supervision from a teacher that retains the full history. These approaches motivate a concrete question for our deployment: how much of a teacher's predictive benefit from uncompressed history can be retained when past interactions are represented by a compact token set that does not depend on the candidate? We study this question for a jointly trained compressor and ranker, with explicit control over the history processed online. We present , a framework that uses autoregressive feedback prediction, as in ARGUS~, while changing the interface between history modeling and candidate scoring. ARGUS uses two-tower fine-tuning to support scoring with precomputed user and item representations. In X-split ARGUS, a history compressor instead produces a set of tokens without conditioning on the candidate, and an online ranker scores ads through cross-at\-ten\-tion to these tokens and representations of recent events. The compressor and ranker are trained end to end, while the history tokens are precomputed offline for reuse during serving. Their number and the length of recent history determine the amount of history processed online. Observed click feedback and click logits for individual candidates from a larger teacher jointly supervise the compressor and online ranker. The teacher scores ads using the uncompressed history. The distillation objective reaches the history compressor through the online ranker, allowing observed feedback and teacher predictions to shape the information retained in the summaries. For online evaluation, we use , our primary internal metric for accepting advertising A/B experiments. ACV reflects the monetary value of advertiser conversions delivered at the same advertising budget, capturing the benefit of improved conversion delivery. Our main contributions are as follows: We introduce a jointly trained history compressor and candidate-aware ranker that combines reusable history tokens with recent events. The number of summary tokens and the length of recent history control the amount of history processed online. We combine autoregressive prediction losses with supervision from the click logits of a teacher using uncompressed history and evaluate the predictive quality retained by the compressed student. In the main offline comparison, X-split ARGUS reduces normalized entropy by 0.81\ Context-aware ARGUS and retains over 70\ over the same baseline. We deploy X-split ARGUS on an advertising surface of our real-time bidding system handling roughly a hundred thousand requests per second. The model meets the existing latency budget using 15\ GPUs of the same type to serve the same traffic. Systems for long histories differ in what they retain, when they compute it, and how candidates access it. Event selection, representation compression, and computation reuse can coexist within the same architecture. Particularly relevant to our setting, TransAct~ combines user embeddings computed in batches with a Transformer conditioned on the candidate to process recent actions. LLaTTE~ scales an asynchronous user model whose cached representations augment a compact online ranker with fresh events and ad context. Both establish the use of separate paths for historical context and recent intent. VISTA~ learns summary tokens for downstream candidate attention and caches these tokens for reuse. Its reported variants include joint training with HSTU and an auxiliary objective for sequence reconstruction. SITA~ organizes stored interest tokens through semantic identifiers and uses each candidate's identifiers to select tokens before target attention. Systems using retrieval retain selected events or historical embeddings. SIM~ retrieves a subsequence relevant to the candidate before applying finer target attention, and TWIN~ aligns the relevance measures of these two stages. TransAct~V2~ selects nearest neighbors from lifelong, recent, and impression histories while explicitly keeping the freshest actions. Representation Memento~ retrieves relevant and diverse temporally aggregated embeddings using a modified maximal marginal relevance criterion. These approaches select context according to the candidate, controlling what is passed to the ranker. Other methods reduce the history representation through aggregation. TWIN~V2~ uses offline hierarchical clustering and cluster-aware target attention; CAUSE~ forms history tokens by category while retaining recent events; and LONGER~ combines local token merging with cross-at\-ten\-tion into a shorter sequence. Representation reduction and computation reuse also interact within serving requests. HELIX~ constructs compressed history states independently of the candidate once per request and lets tokens conditioned on each candidate repeatedly attend to them. This execution strategy differs from computing summaries of long histories offline, as in our deployment. ~ uses stacked cross-at\-ten\-tion from targets to history and batching within each request to share history encoding; OneTrans~ reuses causal sequence computations; and MARM~ caches intermediate history states for multilayer target attention. These reuse strategies reduce repeated computation without necessarily imposing a compact summary representation. Knowledge distillation supplements observed labels with teacher predictions to train a constrained student~. Ranking Distillation~ transfers a teacher's top-ranked unobserved items as weighted supervision, while Collaborative Distillation~ combines soft targets with rank-aware sampling. Privileged Features Distillation~ addresses a different asymmetry: teachers can use predictive features unavailable to the deployed student. Precomputation, storage, and model updates incur additional resources, described below. A daily batch pipeline collects new user events, appends them to the retained user profiles, and runs the history compressor for users with new events. For each such user, it publishes $K$ contextualized history states to an embedding store. The online ranker retrieves these states and combines them with representations of recent events, as described in Section~. Historical representations are therefore reused across requests, while recent behavior remains available through the runtime user profile. We store the compressor states in BF16. For a stored state dimension $d_{ c}$, the uncompressed embedding payload per user is S_{}=2K d_{ c}\ . With standard storage compression, the database of precomputed embeddings occupies hundreds of gigabytes. This footprint refers to the computed embeddings, separately from the retained event histories used by the batch pipeline. The GPU compute required for daily precomputation is small relative to continuous online inference; storing the resulting representations is an additional infrastructure requirement. To inform the update schedule, we evaluate a fixed X-split ARGUS checkpoint on test windows spanning one day, with gaps of zero to four days between the latest training event and the start of each window. User histories and precomputed compressor embeddings are refreshed using events available before each prediction. Daily fine-tuning requires additional GPU compute, but this workload is small relative to continuous online inference. The larger improvement with no gap suggests that more frequent or online model updates could yield further gains.
