In advertising recommendation systems, the ranking order and commercial value of generated candidates are directly tied to platform revenue and the fulfillment of advertiser objectives. To this end, we pursue a more thorough optimization of value perception throughout the system. We propose UniVGD, a framework that incorporates discriminative value awareness at each stage of the generation pipeline to guide the ultimate decision-making process. Sequence-level rewards assign the same credit to all SID decisions, penalizing a useful coarse prefix even when only a later token is wrong. We presented GR4AD-X, a production generative advertising recommendation system that advances reliable SID construction, serving-efficient capacity scaling, and value-aligned generation. Multi-Path SID improves representation reliability by retaining alternative first-level assignments and completing each with a separate residual quantization trajectory. Multi-dimensional capacity scaling strengthens model capability under strict serving constraints, while UniVGD aligns generation with commercial value through prefix-level reward optimization, value-guided beam pruning, and discriminative reranking. Deployed in Kuaishou's large-scale advertising system, GR4AD-X supports high-traffic real-time candidate generation. Offline evaluations and large-scale online A/B tests validate each component, with the full system achieving a cumulative revenue improvement of $3.07\ All online experiments are conducted on the Kuaishou advertising platform, which serves more than 400 million users. The production system integrates reward estimation, online learning, and real-time indexing for continuous model evolution.
