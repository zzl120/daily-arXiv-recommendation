SIDs provide compact item representations, while item text, such as titles and categories, supplies additional content that large language models can use to interpret user preferences~. Incorporating this text, however, creates an imbalance between input cost and supervision: a model may process thousands of history tokens to predict a next-item SID of only a few tokens. This raises a practical question: how can we reduce the cost of processing each history while learning more from it? Reducing input cost calls for a compact representation that retains SID and textual information as well as the sequence of interactions. Learning more from each history also requires looking beyond the next item, which provides only one observation of a user's preferences. Additional future interactions in the training sequence offer further observed targets. A trained teacher recommender can also propose synthetic targets, transferring collaborative information through its item predictions. These additional targets should each be predicted from the observed history, without requiring other target items at inference. Naively training a separate example for every target satisfies this requirement but repeatedly processes the same history. We therefore seek a training structure that shares the history across predictions while keeping the targets separate. To address the challenges, we propose , which combines a compact history with multiple independent target branches . compresses each historical item's SID and text into a small number of learned tokens. SID-conditioned queries select content within each item, and the resulting tokens remain in chronological order so that the LLM can model dependencies across interactions. uses this compact history to predict the next item, additional observed future items, and teacher-proposed synthetic targets. Each target attends to the shared history and its own preceding SID tokens, forming a shallow tree in which targets cannot read one another. Losses from all branches jointly train the history representation and the LLM. Efficient execution is essential to realizing the benefit of this structure. We develop with forward and backward kernels that support the branch visibility pattern without materializing a dense attention matrix. The kernels compute the shared history once and accumulate gradient contributions from every branch. The same sharing principle extends to constrained beam search. Beam hypotheses use the same history but differ in their generated SIDs, so our tree-structured key/value cache stores the history once and maintains separate states for each hypothesis. Ablations show that learning from multiple targets improves recommendation quality with compact history representations. Efficiency measurements demonstrate substantially lower training cost than processing uncompressed SID and text histories. Shared-prefix caching also reduces beam-search latency and memory usage, with the largest benefits at long contexts. M\&B addresses long inputs through interaction token merging and limited supervision through multi-target training . The merger maps each historical item's SID and text embeddings to $N_q$ soft tokens, forming a compact prefix $p_u$ of length $T_u$. For multi-target training, we attach one SID sequence per target to this prefix. A pretrained LLM processes the prefix and target branches with tree attention at every layer, so each target can read the history without reading other targets. The merger and LLM learn jointly from these predictions. At inference, the same structure lets beam hypotheses share the history's KV cache. Item text supplies useful content but can dominate the history's token count. We compress each interaction independently to shorten the history while keeping the sequence of items explicit.
