 We conduct experiments on two personalized search datasets: AOL4PS~ and AE. AOL4PS is a public benchmark for personalized search constructed from the AOL query log, where each sample consists of a query, the user's historical behaviors, and the target document. We adopt the official dataset split. Samples are constructed per user in chronological order: each labeled interaction serves as the target item, with all preceding interactions forming the behavior sequence. AE is a real-world e-commerce search dataset collected from the online search logs of AliExpress. It contains one week of user click behaviors. We use all interactions before the last hour of the final day for training, and use the last hour of the final day for evaluation. Compared with AOL4PS, AE is collected from an industrial search scenario with a much larger item corpus. User queries on AE are typically short and colloquial, whereas product titles are often keyword-stacked by sellers, resulting in a pronounced query-item lexical gap. These properties make AE a more challenging large-scale real-world setting for evaluating IntentGR. For both datasets, we construct a query-level behavior sequence for each sample using the most frequently clicked items under the same query, counting only clicks that occur strictly before the current sample to avoid future information leakage. Different from conventional search~ that primarily relies on query-item relevance, personalized search must incorporate users' historical behaviors to capture individualized preferences. Meanwhile, unlike standard recommendation~ which focuses on user-item interactions to estimate user preference, personalized search is required to distinguish a user's needs under different queries. Therefore, an effective personalized search system should establish a semantic connection among query intent, user preference, and target items. Traditional retrieval approaches typically follow a discriminative framework~, scoring candidate items for a given query or user and returning the top-ranked results, as shown in Figure~ . Retrieval quality thus depends on both the candidate space and the scoring function. Generative retrieval~ reformulates retrieval as a unified sequence generation task in which the model directly generates item identifiers. Typical generative retrieval methods~ follow a two-stage pipeline, as illustrated in Figure~ , which first constructs target identifiers offline from document content, neural indexing models, or item tokenizers, and then trains a retriever to generate these identifier sequences given a query or user context. Fixing the identifiers before retriever training decouples identifier construction from generation, which can leave the resulting identifiers poorly aligned with the downstream retriever's generation objective. As a consequence, the downstream retriever is inherently constrained by how well the learned identifiers preserve item semantics. To bridge the gap, the end-to-end generative retrieval~ jointly learns item tokenization and target SID prediction within a unified framework, as displayed in Figure~ . This enables SIDs to be optimized toward the downstream generation objective, thus becoming more compatible with the generative retriever. {figures/comparison.png} Although end-to-end generative retrieval effectively reduces the mismatch between item tokenization and SID generation, existing designs do not fully satisfy the requirements of personalized search. Recommendation-oriented end-to-end GR methods like ETEGRec~ mainly focus on user-item interactions and target item generation, leaving query semantics insufficiently explored in the end-to-end workflow. Search-oriented generative methods such as ASI++~ move one step further by encoding query semantics into the learned identifier space, yet they treat the query merely as an input signal for aligning and balancing ID assignments, and disregard user behavioral histories entirely. These gaps motivate a more focused question: In this work, we observe that enriching the model input with query-related behavioral evidence can yield clear performance improvements. This suggests that input-level intent evidence is important for generating semantic identifiers that reflect the current search intent rather than drifting toward high-frequency token patterns. However, simply adding such evidence to the input is not sufficient. To fully exploit the introduced evidence, the generative pipeline also requires appropriate mechanisms to align query semantics with the learned identifier space, balance the training distribution of low-frequency queries, and strengthen query conditioning during decoding. To this end, we propose IntentGR, an end-to-end framework for personalized generative retrieval in search. While jointly optimizing item tokenization and generative retrieval, IntentGR introduces four key designs to strengthen intent semantics throughout the retrieval process: . It enriches intent evidence at the input level. By adding a query-related behavior sequence, built from earlier interactions under the same query, QBR places query-level evidence and user-level preference in a single encoder context, helping the model locate the historical interests relevant to the current query. . QSA introduces query semantics as an explicit supervisory signal into the joint optimization of item tokenization and generative retrieval. By aligning query representations in generative retrieval with reconstructed target item representations in item tokenization, QSA provides a shared query-item semantic objective for both components, rather than optimizing them only around item reconstruction and SID prediction. . To mitigate head-query dominance, IntentGR enriches long-tail query data by increasing their occurrence and semantic diversity. This design provides more balanced query-level supervision, allowing long-tail intents to play a more active role in end-to-end learning rather than being overwhelmed by frequent query patterns. . QAM strengthens the guidance of query intent during SID generation. It enhances the attention context used by the decoder with query semantics, further directing the decoder toward the intent expressed in the query. In this way, the decoder generates SID tokens under stronger query guidance, leading to SID sequences that better match the search intent. Together, these designs make query intent a central guiding signal—rather than a single passive input feature—at four complementary points of the end-to-end pipeline: input representation, joint optimization, training distribution, and decoding context. IntentGR provides a systematic way to incorporate query intent across all four stages of end-to-end generative retrieval for personalized search. Traditional information retrieval matches queries to documents using sparse lexical models~ or dense neural retrievers~, while generative retrieval refomulates retrieval as sequence-to-sequence generation. It autoregressively generates semantic identifiers conditioned on the query and the user's interaction history. Research on identifier design has explored a variety of representations. DSI~ assigns hierarchical numeric identifiers to documents, and NCI~ builds on this scheme with a prefix-aware decoder and pseudo-query augmentation. SEAL~ uses document n-grams as identifiers, while SEATER~ organizes item identifiers in a balanced $k$-ary tree and contrastively aligns user representations with identifier paths. TIGER~ uses RQ-VAE to learn discrete SIDs directly from item representations. However, SIDs are typically frozen during retriever training, which prevents them from co-adapting with the generator and makes SID quality a bottleneck for retrieval performance. Motivated by this bottleneck, recent work jointly optimizes the SID tokenizer and generator, an approach we term . Here, ``end-to-end'' refers specifically to joint parameter optimization of these two components. For sequential recommendation, ETEGRec~ couples an RQ-VAE item tokenizer with a generator through two alignment losses, alternating updates before fine-tuning the generator with the tokenizer frozen. For document retrieval, ASI++~ jointly optimizes ID assignment and retrieval through differentiable quantization and introduces a criterion to balance ID usage. GLEN~ initializes lexical IDs with BM25-scored keywords and refines them using ranking signals and a temperature-annealed softmax. NOVO~ jointly refines document n-gram IDs and the retriever until the ID set stabilizes. These methods leave a gap for personalized search: recommendation methods omit query information, while document-retrieval methods disregard user behaviors and treat the query only as a passive decoding condition. This motivates a framework that uses query semantics to explicitly guide both item tokenization and SID generation and incorporates user interaction histories as a retrieval signal. Since the query is the primary semantic signal that guides identifier generation in search, existing generative retrieval methods explicitly incorporate query information at different stages of the pipeline and can be broadly grouped into three categories. 1) Query-based data enrichment. DSI-QG~ represents documents with pseudo-queries to reduce the indexing-retrieval mismatch in DSI~, while NCI~ uses DocT5Query-generated queries and document terms as training inputs. CorpusBrain~ constructs pseudo query-identifier pairs through three pre-training tasks, and CorpusBrain++~ extends it to dynamic corpora through adapter-based continual pre-training with experience replay. 2) Query-driven objective supervision. LTRGR~ adds a margin-based ranking loss after training with the generation loss, while RIPOR~ applies ranking supervision to each document identifier prefix. 3) Query-oriented architectural design. OneSearch-V2~ extends OneSearch~ with a thought-augmented query module that uses LLM-generated chains of thought for training alignment and as additional signals at inference, targeting complex and long-tail queries. Generative retrieval reformulates item retrieval as a sequence generation problem, where the target item is represented and retrieved through a generated identifier sequence~. For personalized item retrieval, the GR framework usually consists of an item tokenizer $T_ $ and a generative retriever $R_ $~. Existing GR baselines mainly follow two optimization paradigms. A key requirement of personalized search is to handle diverse query intents, rather than only performing well on frequent search patterns. However, real-world search logs usually exhibit a highly long-tailed query distribution: head queries provide abundant supervision, while many tail queries appear only a few times but still reflect fine-grained user intents. Directly training on such an imbalanced distribution can make the model biased toward head-query patterns and weaken its ability to learn from long-tail intents. To improve the coverage of tail intents in end-to-end generative retrieval, IntentGR devises Long-Tail Query Enrichment , which enriches long-tail queries at the training data level through repeated sampling and query rewriting. We proposed IntentGR, an intent-enhanced end-to-end generative retrieval framework that strengthens query semantics across four complementary stages: input , optimization , training distribution , and decoding . QBR improves personalized search by introducing query-level behavioral evidence into the input, allowing the model to better capture the collective intent associated with a query. Once this enriched evidence is available, QSA, LQE, and QAM provide additional gains by aligning query semantics with the learned SID space, balancing the training distribution of long-tail queries, and strengthening query conditioning during decoding. Experiments on AOL4PS and the industrial AE dataset show that IntentGR consistently outperforms competitive baselines, with notable improvements on long-tail queries and inactive users. These results indicate that both enriched input evidence and effective integration mechanisms are important for building intent-aware end-to-end generative search systems. Recent end-to-end approaches, primarily explored in recommendation, unify item tokenization and sequence generation within a single model, allowing semantic identifiers to be optimized toward the downstream generation objective. However, these methods often treat the query merely as an input feature, without explicitly leveraging it to guide either identifier learning or sequence generation. This leaves intent guidance weak in both the tokenization and the generation stage, causing generated semantic identifiers to drift toward high-frequency token patterns rather than the current search intent. In this work, we find that incorporating additional query-related evidence into the framework of end-to-end generative retrieval is important. Based on this finding, we propose IntentGR, an intent-enhanced end-to-end framework that strengthens query semantics at four complementary stages of the retrieval pipeline. Query-Aware Semantic Behavior Representation introduces query-level behavioral evidence as a new input signal; Query-Semantic Alignment , Long-Tail Query Enrichment , and Query-conditioned Attention Modulation then serve as integration mechanisms at the optimization, training-distribution, and decoding stages to fully exploit this evidence. Experiments on the public AOL4PS benchmark and AE, a large-scale industrial e-commerce dataset, show that IntentGR improves Recall@10 by 8.11\ over the strongest baseline, with strong gains on long-tail queries.
