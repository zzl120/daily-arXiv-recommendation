Each added layer refines the queries, that is, how the candidate reads the sequence, but every layer reads the same behaviors. In STCA and MixFormer, for example, each layer learns its own projection of the original behavior tokens~. A behavior token never receives information from the request, the candidate or other behaviors, however deep the stack, so added depth buys more reads of a fixed sequence. To get more from depth, the sequence itself has to evolve from layer to layer. Our ablations support this reading: an update that transforms each behavior on its own, without attending to other tokens, is far weaker than one that lets the behavior take in context . How should the sequence be updated? A ranking model imposes three requirements. The updated sequence should reflect the current request , so that the same history can be read differently for different searches. It should be shareable by all candidates of a request , so that scoring thousands of candidates does not multiply its cost. Its attention cost should grow linearly with sequence length . Figure~ checks five designs against these requirements. Most ranking models that update the sequence take information for each behavior from other behaviors . HSTU and OneTrans use causal self-attention across behavior tokens~. EST aggregates the behaviors most similar in content to each token~. This route has three costs. First, the update stays inside the sequence and misses R1. In OneTrans, for example, the non-sequential tokens follow the behaviors under the causal mask, so a past click on running shoes is encoded the same way whether the user now searches for ``track pants'' or ``water bottle''. Second, full causal self-attention over $L$ behaviors has quadratic cost in $L$, which misses R3. HSTU and OneTrans contain that cost with techniques such as sparsification, pruning and caching. Third, a single causal attention stack needs one order for all the groups it processes. Clicks, purchases and exposures over different time windows can be interleaved by time or concatenated in a chosen order with separators.
