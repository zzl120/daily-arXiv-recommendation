We revisited fixed-depth computation in sequential recommendation through diagnostic experiments that reveal heterogeneous depth sensitivity across history items. Motivated by these findings, we proposed , which uses weight-shared recursion with learned item-wise routing to allocate computation adaptively. The key additional component in LoopRec, compared with a fixed-depth sequential recommender, is the depth router. Training therefore needs to ensure that this router is both useful and learnable. First, it should allocate different positions to different depths. Otherwise LoopRec collapses toward nearly fixed-depth behavior and loses the item-level adaptivity motivated in Sec.~. Second, it should remain trainable throughout optimization. Sequential recommendation models an ordered interaction history to rank the next item. Early factorized and neural approaches capture local transition structure via Markov chains, recurrent networks, or convolutional encoders~. Transformer-based recommenders such as SASRec and BERT4Rec then strengthen long-range dependency modeling with self attention~. More recent fixed-depth backbones refine the encoder design with explicit inductive biases, for instance through frequency-domain or filtering mechanisms~. These methods focus on to build stronger sequence encoders under a fixed computation pattern : once the architecture is chosen, each history position is processed by the same depth budget before scoring the next item. LoopRec addresses an orthogonal question. Keeping the recommendation objective and backbone family intact, it asks whether a sequential encoder can allocate recursive computation at the level, so that different positions in the same history need not receive the same depth. Looped Transformers study the repeated application of shared or partially shared Transformer blocks. The Universal Transformer combines shared recurrent transformations with self-attention and supports adaptive per-position halting~, building on adaptive computation time~. Later work shows that looped Transformers can implement non-trivial algorithmic computation~. Recent looped Transformer and looped language-model studies connect repeated depth with latent computation and reasoning~. Mixture-of-Recursions combines shared recursion with token-level adaptive computation for language modeling~. Sequential recommendation models temporal patterns in user interaction histories to predict the next item of interest, supporting personalized ranking on e-commerce and online content platforms~. The dominant paradigm processes a user's interaction history through a fixed number of stacked layers, producing item representations that are then scored against candidates for next-item prediction. This paradigm has driven steady progress over the years, from attention-based models~ to architectures incorporating frequency-domain inductive biases~ and linear recurrences~. Despite their architectural diversity, these methods share a common and largely unquestioned design choice: . We argue that this uniform allocation mismatches the nature of user behavior. A real-world interaction history is inherently heterogeneous~: it mixes routine repeat purchases that carry minimal predictive signal with rare, exploratory, or pivotal interactions that critically shape the user's evolving intent. Intuitively, these items should not demand the same amount of reasoning, yet current models are structurally incapable of differentiating between them, leading to suboptimal performance. We propose , a framework for sequential recommendation with item-level adaptive recursion. For , LoopRec uses a recursive architecture~, reusing a single weight-shared block across all depths. Since every recursion maps through the same parameters, items exiting at any depth naturally produce representations in the same feature space. For , LoopRec places a lightweight binary gate at each recursion boundary that evaluates each item's current state after absorbing the latest round of context, and decides whether it is ready to exit or should proceed to the next recursion. Items exit progressively as they converge, while those that benefit from deeper reasoning remain active. This design requires no auxiliary depth labels, introduces minimal additional parameters, and is readily adaptable to diverse backbone architectures. We conduct extensive experiments on three public benchmarks with four different backbone families. LoopRec consistently outperforms the matched fixed-depth counterpart. Beyond accuracy gains, in-depth analysis of the learned routing reveals interpretable allocation patterns aligned with our post-hoc oracle analysis: the model naturally devotes deeper computation to lower-frequency items and more recent interactions, precisely the groups that an oracle would also allocate more computation to.
