Generative recommendation with semantic IDs represents each item as a sequence of discrete codes derived from its semantic representation and predicts these codes to generate recommendations. Existing semantic-ID recommenders are typically trained with hard labels for the observed next item. Although such supervision identifies the target, it provides no explicit distributional information about alternative items conditioned on the same user history. Sequential recommenders can supply this item-level predictive knowledge, but transferring it to semantic-ID generation is challenging because the teacher and student operate in item and code spaces, respectively. We propose two complementary knowledge-distillation objectives for parallel semantic-ID recommenders, which predict all code positions simultaneously without autoregressive prefix conditioning. Item Distribution Matching reconstructs a catalogue-level item distribution from the student's parallel code predictions and aligns it with the teacher's item distribution. Code Marginal Matching projects the teacher's item probabilities onto each code position using fixed item-to-code assignments, then matches the resulting code marginals to the corresponding student heads. Both objectives transfer the teacher's soft distributional knowledge while preserving the student's parallel prediction structure. Experiments on benchmark datasets show that both methods consistently outperform existing state-of-the-art approaches. On average, IDM improves Recall@10 by 15.39\ These results demonstrate that distillation in either reconstructed item space or code-marginal space can substantially strengthen hard-label supervision for parallel generative recommendation. Early sequential recommenders modeled user behavior through personalized Markov transitions, recurrent networks, and convolutional sequence encoders~. With the adoption of self-attention, SASRec and BERT4Rec introduced causal and bidirectional modeling of interaction histories, respectively~. Subsequent work has also sought to improve sequence representations through self-supervised and contrastive objectives~. In parallel, frequency-domain filtering and hybrid attention have offered alternative ways to capture sequential patterns~. Despite differences in their architectures and training objectives, these methods learn history-dependent scores for individual candidate items. Beyond encoding interaction histories, generative recommendation also revisits how recommendation tasks are formulated. For instance, P5 casts multiple recommendation tasks as text generation~, whereas HSTU models user actions through sequential transduction~. Further developments include hierarchical item--user language modeling, session-wise generation that unifies retrieval and ranking, and the integration of cross features into sequential transducers~. Together, these approaches illustrate the range of architectures and prediction targets explored in generative recommendation. Alongside these developments, another line of research has focused on representing catalogue items through discrete codes drawn from shared codebooks. Vector and product quantization have been used to construct item representations for sequential recommendation~. In generative retrieval, TIGER instead uses content-derived semantic IDs as autoregressive prediction targets~. Subsequent work has refined identifier construction by incorporating language and collaborative signals, semantic tree structures, and diverse code assignments~. More recently, ETEGRec and DIGER have connected identifier learning more closely to recommendation optimization~, while ActionPiece explores context-dependent tokenization of action sequences~. Given such identifiers, a separate modeling choice concerns how their code positions are predicted. Autoregressive SID recommenders generate code positions sequentially, conditioning each prediction on preceding codes. To remove this dependency, RPG predicts long, unordered identifiers through parallel heads and uses graph-guided decoding to recover valid catalogue items~. AsymRec also adopts parallel code prediction with continuous item inputs~. In both architectures, the prediction heads share a history representation without conditioning on previously generated code values, allowing all positions to be evaluated together. Within this paradigm, recent studies have examined the identifiers themselves, including semantic capacity allocation across positions and SimHash-based construction~. An alternative non-autoregressive approach progressively refines predicted codes: LLaDA-Rec uses discrete diffusion with an adaptive decoding order, whereas MaskGR iteratively reconstructs masked positions~. Unlike these iterative schemes, single-pass predictors produce position-wise categorical distributions in one model evaluation. These distributions are combined to score catalogue items, while standard training uses the observed next item's assigned codes as hard targets without specifying graded probabilities for alternative items. Alongside advances in identifier construction and decoding, knowledge distillation transfers predictive information from a teacher to a student~. In conventional recommendation, this has included transferring ranking preferences and collaborative knowledge~, as well as relations among learned representations~. For generative recommenders, knowledge transfer has also been adapted to the student's identifier structure and token predictions. UniGRec transfers collaborative information into its tokenizer and recommender~, while SmartGR incorporates SID hierarchy and beam-level ranking~. TCA4Rec introduces item-level collaborative supervision into autoregressive token prediction~. We formulate item-space and code-marginal distillation for parallel SID predictors and analyze how catalogue-level and head-wise normalization lead to different optimization signals. Sequential recommendation aims to predict a user's next interaction from their historical behavior. Conventional item-level methods, such as SASRec~, learn representations of interaction histories and assign scores to individual candidate items~. Semantic-ID generative recommenders adopt a different paradigm: each item is represented by a sequence of discrete codes derived from its semantic representation, and recommendation is performed by predicting this code sequence~. Different items may share the same code at a given position, while their complete SID sequences distinguish them. This structured representation provides a natural target for generative recommendation~. Early approaches such as TIGER~ predict SID positions autoregressively, conditioning each position on previously generated codes. More recent parallel approaches, including RPG~, predict all positions simultaneously and remove this sequential dependency~. Despite this architectural difference, parallel SID recommenders are still commonly trained with the hard code sequence of a single observed next item. For a given interaction history, the observed next item induces a one-hot target over the vocabulary of each code position. This target identifies the codes assigned to the observed item, but does not specify how probability mass should be distributed among alternative items or code values. In particular, the fixed item-to-code mapping partitions the catalogue into groups of items that share the same code at each position. A hard target only identifies the group containing the observed item; it provides no graded, history-dependent information about the relative likelihoods of the remaining groups. Consequently, hard-label training does not directly expose the student to the predictive uncertainty encoded in alternative candidates. A pretrained sequential recommender can provide such complementary supervision through its history-dependent item scores~. Applying a softmax over the candidate catalogue converts these scores into a teacher distribution that assigns different probabilities to alternative items, including items not observed as the next interaction. Existing studies have transferred collaborative or sequential knowledge to generative recommenders through prefix-conditioned token alignment or distillation with learnable identifiers~. However, these settings differ from a fixed-SID parallel predictor. The teacher produces a distribution over items, whereas the student produces categorical distributions over code values at multiple positions without autoregressive prefix conditioning. The central challenge is therefore how to transfer item-level predictive knowledge into the code distributions of a parallel SID recommender. The fixed item-to-code mapping provides two natural spaces for this transfer. By combining the student predictions corresponding to an item's complete SID and normalizing the resulting scores over valid catalogue items, the parallel student can induce a catalogue-level item distribution. Alternatively, the teacher's item distribution can be projected onto each code position by summing the probabilities of items that share the same code value. These aggregated probabilities form code-level marginals that can be directly matched to the categorical distributions produced by the corresponding student heads. The two spaces preserve different aspects of the teacher's information: catalogue-level matching retains item-level distinctions, whereas code-level marginal matching provides direct supervision for each parallel prediction head. Based on these two spaces, we propose two complementary knowledge-distillation objectives, as illustrated in Figure~. combines the student predictions associated with each item's SID, normalizes the resulting scores over the catalogue, and aligns the induced item distribution with the teacher distribution using soft cross-entropy. instead uses the fixed item-to-code mapping to aggregate teacher item probabilities into a marginal distribution for each code position, and matches these marginals to the corresponding student heads through KL divergence. IDM therefore transfers knowledge through a reconstructed item space, whereas CMM transfers knowledge through a code-marginal space. Both objectives enrich hard-label supervision with history-dependent soft targets while preserving parallel prediction and inference. Our analysis further shows that, under the proposed parameterization, both objectives are driven by teacher-induced code marginals but differ in their student-side normalization: IDM normalizes over catalogue items, whereas CMM normalizes independently within each code head. Empirically, IDM provides stronger improvements in Recall, while CMM yields stronger improvements in NDCG across the evaluated datasets. Our main contributions are summarized as follows: We formulate knowledge distillation from item-level teacher distributions to parallel semantic-ID recommenders, addressing the lack of explicit distributional supervision over alternative code values in conventional hard-label training. We propose two complementary objectives for cross-space distillation. IDM matches the teacher distribution in a catalogue-level item space reconstructed from the student's parallel code predictions, whereas CMM projects the teacher distribution into code-position marginals using the fixed item-to-code mapping. We conduct experiments on three benchmark datasets and compare both objectives with state-of-the-art recommendation methods.
