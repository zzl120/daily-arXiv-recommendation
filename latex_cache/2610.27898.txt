Generative retrieval reformulates this problem as autoregressive item-identifier generation~. In Semantic ID -based methods, each item is represented by a sequence of discrete semantic tokens, enabling retrieval through successive token predictions conditioned on user behavior~. Existing studies have advanced SID-based generative recommendation along two directions. The first focuses on item identifier construction, including semantic tokenization~, load-regulated code assignment~, and hierarchical category-tree representations~. The second improves user-conditioned generation through generative architectures~ and contextual information access~. Despite these advances, existing methods primarily optimize item representations or generation architectures, without explicitly coordinating prefix-dependent user evidence with the organization of candidate branches. This leaves the hierarchical nature of SID decoding insufficiently addressed. More importantly, the two research directions are often considered separately, although they jointly determine the outcome of autoregressive retrieval. SID construction defines the candidate branches available at each prefix, while the generation model determines how user preferences are translated into branch probabilities. Improving either component without considering their interaction may leave a mismatch between the structure of the candidate space and the personalized evidence used to navigate it. The key challenge lies in the changing requirements of prefix-conditioned branch decisions. Near the root of the SID tree, the decoder requires coarse-grained interest evidence, while deeper decisions demand finer information to distinguish sibling branches. As illustrated in Figure~, generating the target SID $ $ requires progressively shifting attention from broad user interests to prefix-specific preferences and fine-grained behavioral cues as the candidate space narrows. For users with diverse and evolving preferences, a fixed user representation or static long-term summary~ may fail to capture the evidence most relevant to each decision. For instance, a user may exhibit broad interests in multiple content categories, while individual branches within each category require more specific behavioral signals for discrimination. Evidence useful for selecting a coarse semantic category may therefore become less informative once the decoder enters a particular subtree. Conversely, fine-grained preferences that are irrelevant to the initial decision may become decisive at deeper levels. This creates a dynamic evidence-selection problem that cannot be fully addressed by simply increasing the capacity of a shared user representation. Instead, personalization should explicitly account for the current generated prefix and its remaining candidate branches. Meanwhile, uneven historical interaction loads introduce another difficulty. As also illustrated in Figure~, popular SID paths attract disproportionately more interactions, potentially dominating branch selection and irreversibly eliminating less frequent but relevant targets. Since branch competition occurs among siblings under the same prefix, global codeword balancing may overlook such local disparities. In particular, the same codeword can appear under different parent prefixes with distinct conditional branch distributions, allowing balanced aggregate loads to conceal highly skewed sibling loads. Moreover, enforcing uniform branch assignments may disrupt semantic proximity, introducing a trade-off between load balance and representation quality. Therefore, effective SID-based retrieval requires both prefix-dependent user evidence and locally balanced candidate branches while preserving semantic structure. To address these challenges, we propose SPAR, a Stepwise Personalized Autoregressive Recommendation framework with Prefix-Balanced Semantic IDs. SPAR integrates two complementary components. First, PATH Decoder constructs coarse-to-fine long-term history views and compresses them into compact memory banks. A decoder-only backbone models recent SID interactions, while prefix-conditioned cross-attention dynamically retrieves relevant long-term evidence at each generation step. User and Event Tokens further incorporate profile information and request-time context into token prediction. Second, RQ-PIB constructs semantic identifiers through residual quantization and rebalances historical interaction loads among child branches sharing the same parent prefix. By selectively reassigning items with minimal additional semantic distortion, it mitigates local branch dominance while preserving semantic structure. Together, PATH Decoder and RQ-PIB improve both the evidence used for branch selection and the organization of competing branches. SPAR further incorporates preference-aligned training to refine generated recommendations. Our main contributions are summarized as follows: We propose PATH Decoder, which dynamically retrieves prefix-relevant evidence from compact coarse-to-fine long-term memories and integrates recent behavior, user profiles, and event context for personalized token prediction. We introduce RQ-PIB to regulate historical interaction loads among sibling branches under the same prefix while limiting additional semantic reconstruction error, addressing local imbalances overlooked by global codeword balancing. Online A/B tests further improve average watch time per user by 3.95\ {Generative Recommendation}} Traditional large-scale recommendation systems typically adopt a multi-stage retrieval architecture, where two-tower models such as YouTubeDNN~ efficiently retrieve candidates through user--item embedding matching. Despite their efficiency, these methods rely on predefined item representations and similarity-based retrieval, limiting the expressiveness of user--item interactions. Generative recommendation offers an alternative paradigm by directly generating recommendation targets. Early efforts such as P5~ formulate recommendation as personalized text generation, while HSTU~ explores scalable sequential modeling of user behavior. More recently, Semantic ID -based generative retrieval has emerged as a promising approach, representing items as sequences of discrete tokens and retrieving candidates through autoregressive generation rather than conventional embedding matching. Existing SID-based methods primarily focus on item tokenization and generative modeling. TIGER~ introduces residual quantization for semantic item indexing and autoregressive retrieval; CoST~ enhances semantic consistency through contrastive quantization; LETTER~ incorporates semantic, collaborative, and diversity objectives into item tokenization; and RPG~ improves generation efficiency through parallel SID decoding. Industrial frameworks, including UniRec~, OneRec~, and OneRec-V2~, further advance generative recommendation through scalable architectures and unified modeling. However, these approaches largely emphasize the construction of item identifiers or the optimization of generation frameworks, while paying limited attention to the hierarchical decision structure induced by SID prefixes. In particular, uneven branch loads and evolving user preferences across decoding steps can undermine retrieval effectiveness. In contrast, our work explicitly addresses these challenges through prefix-conditioned branch balancing and stepwise personalized decoding, jointly improving SID organization and user-aware decision-making at each level of the generation tree. {User Interest Modeling and Personalization}} User interest modeling is fundamental to personalized recommendation. Early sequential methods, including GRU4Rec~, SASRec~, and BERT4Rec~, capture evolving user preferences through recurrent networks and attention-based architectures, while S3-Rec~ further enhances sequential representations through self-supervised learning. Subsequent methods such as UniSRec~ and RecFormer~ incorporate textual semantics to improve generalization, whereas LLM-based approaches, including TALLRec~, LC-Rec~, and CALRec~, explore language-model adaptation for personalized recommendation. Beyond sequential modeling, industrial systems emphasize fine-grained interest extraction: MIND~ captures multiple user interests, DIN~ and DIEN~ introduce target-aware behavior modeling, and MIMN~ and SIM~ extend interest modeling to long behavior sequences through memory and retrieval mechanisms. Despite these advances, existing methods primarily model user preferences through sequence-level representations or target-aware aggregation, where the candidate item is explicitly available. In contrast, SID-based generative retrieval makes a sequence of hierarchical branch decisions, with only a partial target prefix available at each decoding step. Consequently, the relevant user evidence may vary across SID levels and candidate branches, making static user representations or conventional target-aware attention insufficient for fine-grained personalization. To address this distinction, SPAR organizes long-term user behaviors into compact memories at multiple SID-tree depths and models recent interactions through the autoregressive backbone. More importantly, it dynamically retrieves relevant historical evidence conditioned on the current SID prefix, enabling stepwise personalization at the branch-decision level rather than relying solely on sequence-level user representations. {framework.pdf} SPAR consists of three stages, as illustrated in Figure~: RQ-PIB constructs prefix-balanced SIDs offline; PATH Decoder retrieves prefix-relevant long-term evidence and fuses it with recent behavior, profile, and event context for next-token prediction; and preference alignment adapts the generator to recent request-time preferences. In this paper, we presented SPAR, an industrial generative recommendation framework combining RQ-PIB and PATH Decoder to address popularity-driven branch imbalance and insufficient stepwise personalization. RQ-PIB balances historical interaction loads among sibling branches while preserving semantic reconstruction quality, mitigating local branch concentration. PATH Decoder retrieves relevant long-term user memories conditioned on the current decoding state and generated prefix, integrating them with recent behaviors, user profiles, and event context to guide each SID token decision. Together, these components improve branch organization and stepwise personalized decoding.
