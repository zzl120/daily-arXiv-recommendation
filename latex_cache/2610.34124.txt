Generated outputs may fail to identify a unique candidate item, depend on candidate presentation order in the prompt, and lack explicit confidence in the recommendation. Recent studies explore Jev, a model for fast option selection with explicit confidence. Inspired by Jev, we introduce decision-native recommendation, a new paradigm that jointly models item choice and recommendation confidence using LLM representations. It requires valid candidate selection, consistency under candidate reordering, and confidence that reflects recommendation accuracy. We propose Direct Item Choice Estimation , which learns a personalized next-item distribution over supplied candidates from user interaction history and recommends the highest-scoring item with calibrated confidence. Tree-structured attention shares history computation across isolated candidate branches for order-consistent candidate scoring in a single forward pass. On three recommendation datasets, DICE achieves higher top-one accuracy than all evaluated baselines. Separate evaluations show unchanged item choices under tested candidate reorderings and end-to-end speedups of up to approximately $6 $ over the evaluated generation-based methods. We introduced decision-native recommendation as a paradigm that treats valid candidate selection, candidate-order consistency, and confidence that reflects observed recommendation accuracy as joint requirements. DICE realizes these requirements through categorical choice learning with LLM representations, shared-history inference, and held-out calibration. Across three benchmarks, DICE achieves higher top-one accuracy than all evaluated baselines. Additional evaluations support selection of items unseen during recommendation training and order-consistent inference. Matched DICE-I flat--tree measurements demonstrate the computational benefit of history sharing with the scorer held fixed. In calibration evaluations on two benchmarks, DICE-I has lower reported mean ECE than both direct-ranking baselines after method-specific held-out temperature scaling. Selective recommendation and offline routing illustrate how confidence supports prediction selection and computation allocation. Future work will extend decision-native recommendation to settings that couple candidate retrieval with item selection, including abstention when the target is absent from the retrieved pool. We will investigate adaptive calibration as candidate composition and user behavior evolve. Another direction is to extend confidence-guided routing to online serving under dynamic workloads and application-specific latency budgets. This extension will explore routing policies that account for the expected accuracy gain from escalation together with its computational and serving costs. This decision has conventionally been learned as classification over items. Sequential recommenders map a user's interaction history to a distribution over items~, and click-through-rate models estimate the probability that a user engages with a given item~. These recommenders score items directly using representations learned from interaction data and task-specific features. Large language models expand the knowledge available for recommendation by interpreting item descriptions and user histories through representations learned during pretraining~. To exploit this knowledge, most LLM-based recommenders adopt a generation-based paradigm, autoregressively generating the next item's name or a ranked list of candidate names from a prompt~. {figures/teaser.pdf} This paradigm gains world knowledge but gives up the decision form of recommendation, in which the output is a choice among items. Figure~ illustrates three concerns with generation-based recommendation. First, the generated text has to be mapped back to the item space~, and in the experiment, roughly 8--16\ Second, the output is sensitive to how the candidates are presented~. With the user's interaction history and candidate set held fixed, merely reordering the candidate items in the prompt changes the selected item or answer validity in roughly 30--45\ Third, the generated item name alone does not provide explicit confidence in how likely the recommendation is to be correct. In addition, token-by-token decoding adds considerable inference latency. Yet recent work uses Jev~, a System-1 model designed to make fast decisions with explicit confidence rather than generate text~. Given a context and a set of options, Jev directly selects an option and returns a confidence score for that choice. Inspired by this approach, we argue that using LLM knowledge for recommendation does not require language generation. We therefore introduce , a new paradigm that uses LLM representations to jointly model item choice and confidence. Under this paradigm, a recommender should select a valid candidate, preserve its choice under candidate reordering, and provide confidence estimates that accurately reflect how likely that choice is to be correct. Realizing this paradigm raises two challenges. First, the model must learn which supplied item a user is likely to interact with next and estimate confidence in that choice. This requires learning preferences over candidate items from the user's interaction history, while accurate next-item prediction alone does not ensure reliable confidence. Second, the architecture must preserve the temporal order of past interactions without making candidate scores depend on presentation order. A straightforward way to score each candidate is to run the model separately on the user's interaction history and that candidate. However, this processes the same history repeatedly, once for every candidate. The challenge is to share this computation while preserving the history's chronology and keeping candidate scores independent of presentation order. To address these challenges, we propose for personalized next-item recommendation. A pretrained LLM encodes each candidate's description together with the user's chronological interaction history, and a shared scoring head estimates the user's preference for that candidate. These scores are normalized into a choice distribution, trained with candidate-level cross-entropy to favor the observed next item over the alternatives. At inference, DICE recommends the highest-scoring candidate. To estimate confidence in this choice, temperature scaling fitted on held-out data calibrates the choice probabilities without changing the selected item. The recommended item's calibrated probability then estimates how likely that recommendation is to be correct. Tree-structured attention computes all candidate scores in one forward pass by sharing history computation while blocking attention between candidates. The history retains its temporal order, and consistent position assignments keep candidate scores independent of candidate presentation order. We evaluate DICE on three public recommendation datasets. First, DICE achieves the best top-one recommendation accuracy among the evaluated baselines. Additional experiments show accuracy gains with larger backbones and support selection of items unseen during recommendation training . Second, DICE returns valid candidate items, preserves its choices under all tested candidate reorderings, and achieves an end-to-end speedup of up to approximately $6 $ over the evaluated generation-based methods . Third, calibrated decision confidence helps identify recommendations that are more likely to be correct. LLM-based recommenders model preferences using interaction histories, item text, and pretrained knowledge~. Representation methods include UniSRec and Recformer~; LLaRA, CoLLM, and A-LLMRec further integrate sequential or collaborative embeddings with LLM inputs~. Generation-based methods include P5's text-to-text framework~, GenRec~, recommendation tuning in TALLRec~, zero-shot ranking in LLMRank~, and preference supervision in S-DPO and NAPO~. BIGRec and TransRec address grounding generated outputs in the item space~. Reasoning-enhanced methods add rationales or reasoning graphs~ or optimize reasoning--answer trajectories~. RDRec distills rationales~, SelfDR learns from a rationale-informed teacher without test-time reasoning~, and Think When Needed invokes reasoning selectively~. DICE implements decision-native recommendation by learning candidate-choice probabilities from contextual representations and evaluating the selected item's confidence together with output validity and order consistency. Direct LLM scoring avoids answer generation. RankLLaMA scores query--document relevance from contextual representations~, while LlamaRec maps candidate-letter logits to item scores~. InvariRank combines candidate isolation, shared positional framing, and mean token-log-probability scoring for order-consistent ranking in a single forward pass~. We introduce decision-native recommendation as a new paradigm that treats valid candidate selection, candidate-order consistency, and confidence that reflects observed recommendation accuracy as joint requirements. DICE instantiates this paradigm by learning candidate-choice probabilities from LLM representations and calibrating confidence in the selected item. We compare its ranking performance with LlamaRec and InvariRank and assess all three methods' calibration before and after method-specific held-out temperature scaling. SpecInfer and Medusa use tree-structured attention to verify proposed token continuations in parallel~. DICE-I adapts this computation pattern to share history computation across isolated candidate branches while preserving candidate-order consistency. Temperature scaling calibrates neural classifiers and pretrained Transformers~. LLM confidence studies compare conditional probabilities with verbalized confidence~ and evaluate confidence elicitation~. Confidence also supports selective prediction, which studies error at different coverage levels~. For computation allocation, FrugalGPT learns model cascades~, RouteLLM routes using preference data~, and language-model cascades defer using token-level uncertainty~. At the level of individual decisions, System-1.x allocates search by subproblem difficulty~, while REFLEX, Jev-Mem, and JEV-as-a-Judge apply System-1 control to agent actions, memory operations, and selective judgments~.
