Music listening experiences are intrinsically governed by a listener's affective state, which is never static but continuously drifts within a single session~. In affective computing and research, this state is commonly described by the continuous valence and arousal dimensions of Russell's circumplex model~ . Indeed, emotion-elicitation studies show that listening to even a single minute of music reliably induces distinct shifts~, meaning a listener's mood can fluctuate multiple times throughout a listening session. Despite this continuous drift, contemporary recommender systems remain largely blind to real-time emotional shifts. When systems incorporate affect, they typically infer it from past listening logs, static context attributes, or explicit self-reports~. Recent models such as ACE~, for instance, anchor each user to the centroid of previously consumed items. While effective in offline benchmarks, such static anchors remain fixed even when a listener's mood departs from their historical average during an active session. Aligning recommendations with a listener's immediate affective state requires capturing this signal during the session and passing it to the ranking pipeline at request time. In practice, establishing this live closed loop exposes three deeply connected operational and methodological bottlenecks across the system pipeline. First, at the serving infrastructure level, production recommendation systems are engineered around episodic logs of discrete actions, such as clicks, plays, and ratings~. While context-aware models incorporate situational factors~, they typically assume discrete attributes known ahead of time. In contrast, continuous physiological telemetry sampled at hundreds of hertz in the browser is noisy and susceptible to artifacts, requiring real-time filtering and feature extraction before yielding a stable affective estimate~. Even modern serving frameworks designed for low-latency ranking, such as WarpRec~, provide no native hook to forward continuous in-browser telemetry directly to custom ranking models. Second, at the recommendation model level, streaming this affective signal addresses only half the challenge, because the visitor in front of the screen is typically an anonymous newcomer. Collaborative filtering models allocate static user embedding tables that require expensive retraining or per-user fold-in to represent new visitors, unless users are parameterized purely through consumed items~. Sequential architectures, such as self-attentive transformers , elegantly bypass this user-table bottleneck by encoding an ordered sequence of interactions directly into a dynamic user state without persistent user identifiers. Yet, because sequential models operate strictly over discrete item tokens, they lack native mechanisms to fuse external, continuous affective factors during candidate scoring. Compounding this divide, existing affect-aware techniques bind continuous signals directly to model-specific training objectives~, leaving researchers without a shared abstraction to project live affect into the recommendation process across structurally different models. Third, s have historically remained isolated from the web ecosystem. While implicit affect sensing has explored video feeds to detect emotion~, wearable headsets are able to record raw brain signals from which affective states can be inferred ~. Although web-based streaming is increasingly explored, accessing wearable telemetry has traditionally relied on third-party drivers. The emerging W3C Web Bluetooth specification} removes this barrier, enabling browsers to pair directly with Bluetooth Low Energy hardware without local installation. Yet, the web ecosystem still lacks an open, end-to-end architecture to translate continuous in-browser bio-signals into live recommendation context. To resolve these challenges within a unified system, we present a web platform that connects in-browser bio-sensing directly to real-time music recommendation. The platform integrates two decoupled core components: an in-browser acquisition pipeline that pairs with a consumer device over Web Bluetooth, preprocesses the raw bio-signals in real time, and maps them to normalized valence and arousal proxy coordinates; and an affective adapter that unifies candidate scoring across different model families. This adapter allows anonymous visitors to interact with the system by providing a small set of favorite tracks that capture their musical preferences, while their live signal steers recommendations in real time without model retraining. Consequently, structurally different models, such as graph neural networks~ and sequential recommendation~, can be swapped at serving time without modifying the web client or serving infrastructure. Live affective music recommendation requires coordinating three distinct operational tasks: in-browser sensor communication, continuous V/A proxy estimation, and low-latency candidate scoring. The system addresses these demands through a decoupled microservice architecture that isolates candidate ranking from sensor-specific processing . Four independent services carry these responsibilities: the serves the interactive web application to the client browser; the handles music track metadata retrieval; the is dedicated to real-time preprocessing and affective feature extraction; and the scores candidates across the catalog using WarpRec~. Two core contributions bridge these independent services into an end-to-end pipeline. First, a standalone library} connects to the headband via Web Bluetooth and streams EEG data to the , which computes normalized proxy coordinates. Second, an hooks into WarpRec models with minimal implementation effort. In addition to live projection, this adapter transforms offline models of different families into their live affective variants, serving anonymous visitors on the fly without retraining. This architectural separation keeps the recommendation model completely agnostic to the physical origin of the affective signal. As long as an input source produces values within this normalized range, the ranking models function identically, regardless of the underlying sensing modality. HTTP and WebSocket protocols decouple these microservices, providing deployment flexibility across heterogeneous topologies. This modularity allows the platform to run either as a self-contained local edge deployment or as a distributed deployment across dedicated nodes. The system comprises acquisition and processing modules. signals are acquired from a Muse~2 device} using Muse-js,} with four channels sampled at 256~Hz. In the backend, a dedicated thread maintains a circular buffer containing 1024 samples per channel, corresponding to 4~s of EEG. Once the buffer is full, the acquired data are retrieved and converted into an MNE Raw data structure~. Signal quality is assessed using MNE's channel detection function} to identify channels with anomalous signal characteristics. Visual inspection complements automated assessment, supporting noise identification and headset repositioning. Preprocessing involves causal bandpass filtering between 1 and 40~Hz. NeuroKit2} estimates theta , alpha , and beta powers. A second circular buffer stores 20 successive observations. Temporal smoothing averages each feature across these observations, separately for each band and channel, attenuating short-term fluctuations. The operates inside the service as a decoupled module that bridges offline-trained ranking models with live affective serving . Its objective is to equip the recommendation backbones with a live-affect scoring mechanism, allowing them to serve anonymous web visitors without persistent user embeddings or online retraining. The design stems from the affective grounding principles introduced in ACE~. Specifically, we abstracted how ACE infuses valence and arousal into representation learning, generalizing its mechanics to support structurally different recommendation families. At serving time, the adapter operates on three inputs: the tracks selected by the user, the live coordinates, and the pre-computed item embeddings, each associated with an item-level profile. In response, it outputs the top-$k$ ranked tracks, conditioned on the input V/A proxy coordinates. This architecture resolves two fundamental bottlenecks of live deployment: anonymous visitor representation and model heterogeneity. First, traditional collaborative filtering models rely on static user embeddings that fail to handle unobserved web visitors~ {DBLP:reference/sp/KorenRB22}. The adapter overcomes this barrier by projecting an anonymous visitor into the latent space via averaging the embeddings of the visitor's selected tracks, bypassing user tables and eliminating online retraining~. Second, recommenders fundamentally differ in how they score candidates . The adapter bridges this divide and makes ranking models fully interchangeable by exposing a serving interface that is based solely on the visitor's history and live coordinates. To isolate platform performance from network delays, we benchmarked the system locally on a MacBook Pro M4 via WarpRec~ . The system serves the Lastfm-VADS catalog, which provides inferred item-level V/A profiles~. The demonstration invites attendees to experience the system through an interactive web application . We show the system across two distinct operational scenarios, highlighting both interaction and a hardware-free alternative. In this primary scenario, attendees experience the complete closed-loop interaction driven by consumer . First, the visitor configures their listening profile by choosing a recommendation model between and and selecting up to ten favorite tracks from the catalog to initialize preferences . Next, the web application connects to a Muse~2 headband over the Web Bluetooth API, displays real-time electrode contact check, and verifies signal stability through the quality gate . Once the signal stabilizes, the system continuously maps the incoming stream into normalized V/A proxy coordinates, projecting them onto Russell’s 2D circumplex plane at 8\,Hz . Finally, the system captures the current coordinates and generates a refreshed top-10 recommendation list . Attendees can listen to V/A-conditioned tracks through the embedded player and record three-tier ratings . Explicit session resets clear all in-memory buffers, WebSocket connections, and user data. This secondary scenario demonstrates an alternative interaction mode that operates entirely without specialized hardware. The attendee selects the manual flow, bypassing the sensor pairing and calibration screens to navigate Russell's 2D plane directly with an interactive cursor. Direct manipulation of this 2D cursor across different emotional quadrants enables visitors to inspect how the ranking models dynamically re-score the catalog in real time. This capability is guaranteed by the system's input swappability feature: the architecture accommodates interchangeable input modalities without downstream modifications, provided that the exchanged data format for valence and arousal coordinates remains identical. Real-time affective music recommendation has long been constrained by two practical barriers: wearable devices tied to third-party drivers, and recommendation pipelines that depend on static user histories. To overcome both limitations, our web platform pairs consumer hardware directly with the browser via Web Bluetooth. By mapping raw signals onto Russell's valence-arousal plane, the architecture decouples physiological processing from candidate scoring. This separation enables an affective adapter to serve anonymous visitors on the fly across both graph neural networks and sequential transformer backbones. Under a shared live-affect scoring mechanism, the module infers musical preferences from a few favorite tracks and balances them against the live EEG-derived control signal, bypassing static user embeddings. All signals, affective coordinates, and preferences are processed ephemerally in memory and deleted after each session. The platform uses affective telemetry as a control signal to steer recommendations, rather than for validated emotion recognition or a clinical assessment of emotional health.
