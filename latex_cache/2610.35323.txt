Personalized Web search and recommendation retrieve relevant items from large catalogs using a user's ordered interaction history and, when available, a current query. Large language models provide rich semantic representations of items and queries, but growing histories increase both training and inference costs. Repeatedly encoding the same items across users and requests adds further overhead. Efficient personalized retrieval therefore requires addressing three challenges: reusing item semantics while retaining request-dependent contextual modeling; preserving both semantic information and interaction patterns in compressed representations; and jointly optimizing item and retrieval encoders when cached representations reduce the amount of differentiable computation. Existing methods address different aspects of these challenges. Recformer~ jointly models item text and interaction sequences, while processing history text for each request. Token Factory~ converts heterogeneous features into soft tokens and compresses recommendation inputs, and ICAE~ learns compact memories through autoencoding and language modeling. These approaches demonstrate the value of compression. For personalized retrieval, however, an item representation must also remain useful when composed into different histories, and text reconstruction alone does not directly supervise interaction patterns. Representation caching offers a complementary way to reduce repeated computation. GNNAutoScale~, for example, reuses historical embeddings in graph neural networks. Applying caching to language-model-based item encoding requires coordinating encoder updates with the gradient paths available through cached representations, without allowing full-history re-encoding to consume the savings from reuse. Our central idea is to separate stable item semantics from dynamic request context. We propose omposable and eusable tem emory . An item memory encoder independently maps each item to a compact block of continuous memories shared across users and requests. A request encoder composes these blocks in interaction order and incorporates an optional query to generate a personalized retrieval representation. This design moves repeated item-text encoding offline while preserving contextual modeling of the current history and information need. Preserving item-text semantics allows retrieval to use the LLM's pretrained semantic knowledge alongside learned interaction patterns. To support semantic compression and sequence learning together, CRIM combines learnable summary tokens with segment-level readout tokens, termed REC tokens. Summary tokens encode each item's semantics into a small number of continuous vectors. REC tokens read out intermediate history prefixes to predict subsequent interactions, introducing supervision throughout the sequence. We further develop a joint training mechanism that combines cached memories with sampled live re-encoding. Only a few history positions are re-encoded for each request, allowing retrieval gradients to update the IME through those positions. The remaining positions reuse cached memories and participate in RE training. Periodic refreshes keep the memory cache aligned with the evolving encoder. This mechanism allows item memories to adapt to the retrieval objective while limiting the cost of re-encoding long histories.
